## 🧪 דברים ששווה לנסות

1. **ערכו מחיר ב-`menu.json`** ורעננו. הקוד לא השתנה.
2. **`F12` ← Network ← Slow 3G ← רענון** – שלד הטעינה בפעולה.
3. **Network ← Offline ← רענון** – הודעת שגיאה וכפתור "ניסיון נוסף".
4. **הוסיפו פריטים להזמנה, סגרו את הדפדפן, פתחו שוב** – ההזמנה שם.
5. **לחצו 🌙** – מצב כהה, ונשמר.
6. **`Ctrl+Shift+M`** – מצב מכשיר נייד: ☰ פותח את הניווט, `Esc` סוגר.
7. **`Ctrl+P`** – תפריט מוכן להדפסה.
8. **`Tab` מהתחלה** – קישור הדילוג צונח פנימה בזהב.

## 📝 הערות

- **קובץ הווידאו (`media/cafe-morning.mp4`) לא נמצא כאן בכוונה** – לא מעלים
  וידאו כבד ל-Git. תראו את תמונת ה-poster ואת הנגן, וזה בדיוק מה שרואה
  מי שהחיבור שלו אטי.
- **התמונות הן SVG שנוצרו לקורס**, לא צילומים. אפשר להחליף בתמונות אמיתיות.
- **`og:image` בנתיב יחסי.** ברגע שהאתר עולה לשרת אמיתי, זה הדבר הראשון
  להחליף לכתובת מלאה (`https://...`) – אחרת התצוגה בוואטסאפ תישבר.
- **הטופס לא נשלח לשום מקום** (`action="/reserve"` מדומה). ולידציה בצד לקוח
  היא נוחות בלבד; הבדיקה האמיתית היא בשרת.
