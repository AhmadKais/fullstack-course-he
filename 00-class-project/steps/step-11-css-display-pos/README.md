# 🏗️ שלב 11 – כותרת דביקה ותווית מבצע

## 🎯 מה מוסיפים היום

- מצמידים את הכותרת לראש המסך ב-**`position: sticky`** – היא נשארת בזמן גלילה.
- מסתירים את **קישור הדילוג** מחוץ למסך, כך שיופיע רק בלחיצת `Tab`.
- מוסיפים תווית "נפתח ב-07:00" שצפה על תמונת הראשי, בעזרת `absolute` בתוך `relative`.
- מבינים `z-index` – ולמה הוא לפעמים לא עובד.

</div>

<div dir="rtl" align="right">

## 🌍 למה זה ככה בעולם האמיתי

### חמשת ערכי `position`, וההבדל היחיד שחשוב

| הערך | האם תופס מקום? | ביחס למי הוא זז |
|-------|------------------|-------------------|
| `static` | ✅ | ברירת מחדל – לא זז |
| `relative` | ✅ **המקום נשמר** | ביחס למקומו המקורי |
| `absolute` | ❌ **המקום נעלם** | ביחס להורה הממוקם הקרוב |
| `fixed` | ❌ | ביחס לחלון הדפדפן |
| `sticky` | ✅ | רגיל, עד שנוגע בגבול |

**כל הבלבול נמצא בעמודה האמצעית.** `relative` מזיז אלמנט ומשאיר את החור שלו.
`absolute` מוציא אותו מהזרימה לגמרי, והאלמנטים שאחריו זזים למעלה כאילו לא היה שם.

### הזוג `relative` + `absolute`

זה **הדפוס** הכי שימושי ב-CSS. תווית "מבצע" על תמונת מוצר, "X" לסגירת חלונית,
מספר על אייקון עגלה – כולם אותו דבר:

</div>

```css
.hero        { position: relative; }   /* ההורה: "מדוד ממני" */
.hero::after { position: absolute; top: 16px; right: 16px; }
```

<div dir="rtl" align="right">

**מה קורה בלי ה-`relative` על ההורה?** האלמנט ימשיך לחפש למעלה עד שיגיע
לחלון הדפדפן, והתווית תנחת בפינת המסך במקום על התמונה. **זה הבאג מספר אחת
של השיעור הזה.**

### `sticky` – למה זה לפעמים לא עובד

</div>

```css
.site-header {
  position: sticky;
  top: 0;
}
```

<div dir="rtl" align="right">

`sticky` מתנהג רגיל עד שהגלילה מגיעה לגבול שהגדרתם, ואז "נתפס".

**שלוש סיבות שזה לא עובד אצלכם:**
1. **אין `top`.** בלי הגבול, אין למה להיתפס. זו הסיבה הכי נפוצה.
2. **להורה יש `overflow: hidden`** (או `auto`). זה מבטל sticky לחלוטין,
   וזה קשה לאיתור כי ההורה יכול להיות שלוש רמות למעלה.
3. **ההורה נמוך מדי.** אלמנט sticky לא יוצא מגבולות ההורה שלו.

### `z-index` – שלושה כללים

1. **עובד רק על אלמנט ממוקם** (כל דבר שאינו `static`). `z-index` על אלמנט רגיל
   פשוט מתעלמים ממנו.
2. **מספרים קטנים.** 10, 50, 100 – לא 9999. הקפיצה ל-9999 היא סימן שאיבדתם
   שליטה, ואז מישהו יכתוב 10000.
3. **הקשר ערימה:** אלמנט עם `z-index: 5` בתוך הורה עם `z-index: 1` **לעולם**
   לא יעבור אלמנט אחר עם `z-index: 2`. הוא כלוא בתוך ההורה שלו.

</div>
<div dir="rtl" align="right">

## 🔨 שלב אחר שלב

### 1. קישור הדילוג – הפתרון הנכון

בשלב 06 הוספנו קישור דילוג, והוא היה גלוי בראש כל דף. עכשיו נעשה את זה כמו שצריך:

</div>

```css
.skip-link {
  position: absolute;
  top: -100px;              /* מחוץ למסך */
  right: 12px;
  z-index: 100;
  background-color: #c9a227;
  padding: 10px 16px;
}

.skip-link:focus {
  top: 0;                   /* חוזר פנימה בלחיצת Tab */
}
```

<div dir="rtl" align="right">

> ⚠️ **למה לא `display: none`?** כי אז הקישור **יוצא מסדר ה-Tab לגמרי** ולא ניתן
> להגיע אליו לעולם. אותו דבר עם `visibility: hidden`.
> הזזה מחוץ למסך מסתירה מהעין ומשאירה למקלדת. זה ההבדל.

**נסו:** רעננו את הדף ולחצו `Tab` פעם אחת.

### 2. הכותרת הדביקה

</div>

```css
.site-header {
  position: sticky;
  top: 0;
  z-index: 50;
}
```

<div dir="rtl" align="right">

ה-`z-index: 50` דרוש כדי שהכותרת תעבור **מעל** התוכן שנגלל תחתיה.

### 3. הניווט בשורה אחת

</div>

```css
#main-nav li {
  display: inline-block;
  margin-left: 18px;
}
```

<div dir="rtl" align="right">

`<li>` הוא `block` כברירת מחדל – כל אחד תופס שורה. `inline-block` מציב אותם
בשורה **אבל מאפשר להם רוחב, גובה וריפוד** (מה ש-`inline` רגיל לא מאפשר).

**זו הייתה הדרך לפני Flexbox.** בשלב 12 נחליף אותה – ותראו כמה זה פשוט יותר.

### 4. התווית הצפה

</div>

```css
.hero { position: relative; }

.hero::after {
  content: "נפתח ב-07:00";
  position: absolute;
  top: 16px;
  right: 16px;
  background-color: #c9a227;
  border-radius: 999px;
  padding: 6px 12px;
}
```

<div dir="rtl" align="right">

**`content` היא חובה בפסאודו-אלמנט.** בלעדיה – גם `content: ""` ריק –
האלמנט פשוט לא נוצר.

**`border-radius: 999px`** הוא הטריק לגלולה מושלמת: כל ערך גדול מחצי הגובה
נותן את אותה תוצאה, ולא צריך לחשב.

## 💻 מה נוסף ל-`style.css` היום

</div>

```css
/* ============================================================
   שלב 11 · CSS מודול 4 – Display ומיקום
   ============================================================ */

/* קישור הדילוג: קיים תמיד, נראה רק כשמגיעים אליו ב-Tab */
.skip-link {
  position: absolute;
  top: -100px;
  right: 12px;
  z-index: 100;
  background-color: #c9a227;
  color: #2b2b2b;
  padding: 10px 16px;
  border-radius: 0 0 8px 8px;
}

.skip-link:focus {
  top: 0;
}

/* הכותרת נשארת למעלה בזמן גלילה */
.site-header {
  position: sticky;
  top: 0;
  z-index: 50;
}

#main-nav li {
  display: inline-block;   /* מרשימה אנכית לשורה אחת */
  margin-left: 18px;
}

#main-nav a {
  display: inline-block;
  padding: 6px 4px;
  text-decoration: none;
}

/* הורה ממוקם – נקודת הייחוס לכל מה שממוקם בתוכו */
.hero {
  position: relative;
}

/* תווית "פתוח עכשיו" צפה על תמונת הראשי */
.hero::after {
  content: "נפתח ב-07:00";
  position: absolute;
  top: 16px;
  right: 16px;
  background-color: #c9a227;
  color: #2b2b2b;
  font-size: 0.85rem;
  padding: 6px 12px;
  border-radius: 999px;
}

.hero h1 {
  margin-top: 16px;
}
```

<div dir="rtl" align="right">

## 👀 מה רואים במסך

- **גללו למטה** – הכותרת עם הלוגו והניווט נשארת בראש המסך.
- קישור הדילוג נעלם. **לחצו `Tab`** אחרי רענון – הוא צונח פנימה בזהב.
- על תמונת הראשי, בפינה הימנית העליונה, גלולה זהובה: "נפתח ב-07:00".
- פריטי הניווט בשורה אחת במקום זה מתחת לזה.

## ✋ אתגר לכיתה

1. הוסיפו כפתור **"חזרה למעלה"** שצף בפינה השמאלית התחתונה של המסך
   ולא זז בגלילה. איזה `position`?
2. **בדיקה:** הוסיפו `overflow: hidden` ל-`body`, רעננו וגללו. מה קרה לכותרת?
   הסירו.
3. התווית "נפתח ב-07:00" נראית טוב במסך גדול ומכסה חצי תמונה בטלפון.
   איך נסתיר אותה במסכים צרים? (רמז: בשלב 14 נלמד את התחביר – נסו לנחש)

</div>
</div>

<details dir="rtl">
<summary><b>💡 הצגת הפתרון</b></summary>

<div dir="rtl" align="right">

**1. `fixed`** – ביחס לחלון הדפדפן, לא לדף. הוא לא זז בגלילה בכלל.
(`sticky` היה נצמד רק אחרי שהיינו גוללים אליו.)

`.to-top { position: fixed; bottom: 20px; left: 20px; z-index: 40; }`

ב-RTL נשתמש ב-`left` כי "הפינה הרחוקה" היא שמאל. בשלב 16 נראה את
`inset-inline-end`, שנותן את זה בלי לחשוב על כיוון.

**2. הכותרת הפסיקה להיות דביקה** – היא נגללת החוצה כמו כל אלמנט רגיל.
`overflow` על אב קדמון **מבטל sticky**, וזה הבאג הכי מתסכל בנושא הזה,
כי שום דבר לא מדווח על שגיאה.

**כשה-sticky לא עובד:** בדקו `top`, ואז חפשו `overflow` בכל ההורים.

**3. Media Query:**

`@media (max-width: 699px) { .hero::after { display: none; } }`

זה בדיוק מה שכתוב בקובץ שלנו בשלב 14.

</div>
</details>

## 🔍 טעויות שראינו בכיתה

| הטעות | מה קורה |
|--------|----------|
| `absolute` בלי `relative` על ההורה | האלמנט קופץ לפינת המסך |
| `sticky` בלי `top` | מתנהג כמו `static` |
| `overflow: hidden` על הורה | מבטל `sticky` בלי אזהרה |
| `z-index` על אלמנט `static` | מתעלמים ממנו |
| `display: none` לקישור דילוג | הופך אותו לבלתי נגיש – ההפך מהמטרה |
| `::after` בלי `content` | לא נוצר כלום |

</div>
