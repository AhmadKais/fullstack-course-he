## 🎯 מה מוסיפים היום

- הופכים את הגלריה ל-**Grid רספונסיבי** בשורה אחת: `auto-fit` + `minmax`.
- הופכים את רשימות התפריט לרשת כרטיסים.
- בונים ב"צרו קשר" פריסת **שתי עמודות**: מפה וטופס זה לצד זה.
- מבינים מתי Grid ומתי Flexbox.

</div>

<div dir="rtl" align="right">

## 🌍 למה זה ככה בעולם האמיתי

### ההבדל בין Grid ל-Flexbox – משפט אחד

| | Flexbox | Grid |
|---|---------|------|
| ממדים | **ציר אחד** | **שני צירים** |
| מי קובע | התוכן | הפריסה |
| מתאים ל | סרגל, שורת כפתורים, יישור זוג | גלריה, רשת כרטיסים, שלד עמוד |

> **Flexbox** = "סדר את הדברים האלה בשורה, ותן להם למצוא את המקום שלהם."
> **Grid** = "הנה הרשת. מלא אותה."

הכותרת שלנו היא Flex – שני פריטים בשורה. הגלריה היא Grid – רשת של שורות ועמודות.
**זו לא תחרות; רוב האתרים משתמשים בשניהם, בכל דף.**

### השורה שנראית כמו כישוף

</div>

```css
grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
```

<div dir="rtl" align="right">

נפרק אותה מבפנים החוצה:

| החלק | מה הוא אומר |
|-------|---------------|
| `minmax(260px, 1fr)` | "עמודה: לפחות 260px, ואם יש עוד מקום – חלק שווה ממנו" |
| `auto-fit` | "כמה עמודות כאלה שנכנסות – תחליט בעצמך" |
| `repeat(…)` | חוזר על הדפוס |

**התוצאה:** במסך 1200px → 4 עמודות. ב-800px → 3. בטלפון → 1.

**בלי אף Media Query אחת.** זה כל ההבדל בין CSS של 2015 ל-CSS של היום:
פעם היינו כותבים שלושה בלוקים של `@media` בשביל בדיוק את זה.

**`fr` הוא יחידה חדשה** – "חלק מהמקום **הפנוי**". `1fr 2fr` = שליש ושני שליש,
אחרי שהורידו את ה-`gap`. ב-`%` הייתם צריכים לחשב את זה בעצמכם.

</div>

## 🔨 שלב אחר שלב

### 1. הגלריה

</div>

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 20px;
}
```

<div dir="rtl" align="right">

זה הכול. שלוש התמונות שהיו זו מתחת לזו הופכות לרשת שמתאימה את עצמה.

### 2. רשת התפריט

</div>

```css
.menu-cat ul,
.menu-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 14px;
}

.menu-cat li {
  margin-bottom: 0;   /* ה-gap מטפל ברווח עכשיו */
}
```

<div dir="rtl" align="right">

**שוב מחקנו קוד.** ה-`margin-bottom` שהוספנו בשלב 10 מיותר – `gap` מטפל
בכל הרווחים, גם אנכית וגם אופקית.

**`.menu-grid` עדיין לא קיים ב-HTML.** הוא ייווצר בשלב 24, כשהתפריט
ייבנה מ-JavaScript. הכנו לו את המקום.

### 3. שתי עמודות ב"צרו קשר"

הוספנו **עטיפה אחת ב-HTML**:

</div>

```html
<div class="contact-layout">
  <section>
    <h2>איך מגיעים</h2>
    <iframe ...></iframe>
  </section>
  <section>
    <h2>הזמנת שולחן</h2>
    <form ...>...</form>
  </section>
</div>
```

<div dir="rtl" align="right">

ואת ה-CSS:

</div>

```css
@media (min-width: 900px) {
  .contact-layout {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 32px;
    align-items: start;
  }
}
```

<div dir="rtl" align="right">

**שימו לב לשלושה דברים:**

1. **ה-Grid נמצא בתוך `@media`.** מתחת ל-900px אין `display: grid` בכלל,
   והשניים נערמים – בדיוק ההתנהגות הרצויה בטלפון. **זה Mobile First:**
   ברירת המחדל היא המסך הקטן, והרוחב הוא התוספת.
2. **`align-items: start`** – בלעדיו שני התאים נמתחים לגובה זהה, והטופס
   הקצר יקבל שטח לבן ענק מתחתיו.
3. **הוספנו `<div>` ל-HTML לצורכי פריסה, וזה בסדר גמור.** `<div>` פסול רק
   כשהוא מחליף תג סמנטי קיים. כאן הוא לא מחליף כלום.

### 4. ארבע דרכים למקם פריט ברשת – לידיעה

</div>

```css
grid-column: 1 / 3;        /* מקו 1 עד קו 3 = שתי עמודות */
grid-column: span 2;       /* "תפוס שתיים", בלי לספור קווים */
grid-area: header;         /* לפי שם, עם grid-template-areas */
grid-row: 1 / -1;          /* -1 = הקו האחרון. שימושי מאוד */
```

## 💻 מה נוסף ל-`style.css` היום

</div>

```css
/* ============================================================
   שלב 13 · CSS מודול 6 – Grid
   ============================================================ */

/* auto-fit + minmax = רספונסיבי בלי אף Media Query */
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 20px;
}

.gallery figure {
  margin: 0;
}

.gallery figcaption {
  padding-top: 8px;
  color: #6b6257;
  font-size: 0.9rem;
}

.menu-cat ul,
.menu-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 14px;
}

.menu-cat li {
  margin-bottom: 0;
}

/* דף "צרו קשר": מפה וטופס זה לצד זה במסך רחב */
@media (min-width: 900px) {
  .contact-layout {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 32px;
    align-items: start;
  }
}
```

## 👀 מה רואים במסך

- **הגלריה:** שלוש תמונות בשורה אחת במסך רחב.
  **גררו את קצה החלון לאט** – ברוחב מסוים הן קופצות לשתיים, ואז לאחת.
  זה `auto-fit` מחשב מחדש בזמן אמת.
- **התפריט:** כרטיסים בשתיים־שלוש עמודות במקום רשימה ארוכה. הדף התקצר בחצי.
- **דף "צרו קשר":** במסך רחב – מפה בצד אחד, טופס בשני. בטלפון – זה מתחת לזה.

## ✋ אתגר לכיתה

1. שנו את `minmax(260px, 1fr)` בגלריה ל-`minmax(400px, 1fr)`. כמה עמודות יש עכשיו?
2. גרמו לתמונה הראשונה בגלריה לתפוס **שתי עמודות**.
3. **`auto-fit` מול `auto-fill`:** החליפו והביטו במסך רחב מאוד עם שתי תמונות בלבד.
   מה ההבדל?

</div>
</div>

<details dir="rtl">
<summary><b>💡 הצגת הפתרון</b></summary>

<div dir="rtl" align="right">

**1.** פחות. במסך 1200px: `1200 / 400` = **שתיים במקום ארבע**. המינימום קובע
כמה עמודות אפשר לדחוס, ולכן הוא הידית האמיתית של הפריסה.

**2.**

`.gallery figure:first-child { grid-column: span 2; }`

⚠️ **מלכודת:** אם יש רק עמודה אחת (בטלפון), `span 2` על עמודה אחת גורם
לדפדפן ליצור עמודה נוספת – והרשת נשברת. בפועל כותבים את זה בתוך
`@media (min-width: 700px)`.

**3.**
- **`auto-fit`** – עמודות ריקות **קורסות לרוחב 0**, והפריטים הקיימים נמתחים
  ותופסים את כל הרוחב.
- **`auto-fill`** – העמודות הריקות **נשארות**, והפריטים נשארים בגודלם עם
  שטח ריק מצדם.

**מתי מה:** רוצים שהפריטים ימלאו את השורה – `auto-fit`. רוצים שהגודל
יישאר עקבי בין דפים עם מספר פריטים שונה – `auto-fill`.

</div>
</details>

## 🔍 טעויות שראינו בכיתה

| הטעות | מה קורה |
|--------|----------|
| `display: grid` על הילדים | הרשת מוגדרת על **ההורה** בלבד |
| `grid-template-columns: 1fr 1fr` בטלפון | שתי עמודות דחוסות. `auto-fit` פותר |
| `%` במקום `fr` | ה-`gap` לא נלקח בחשבון וגולשים מהרוחב |
| בלי `align-items: start` | תאים נמתחים לגובה השורה |
| Grid לשורת כפתורים | זה ציר אחד. Flexbox פשוט יותר |
