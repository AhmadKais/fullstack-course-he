## 🎯 מה מוסיפים היום

- יוצרים את **`css/style.css`** – הקובץ שילווה אותנו תשעה שיעורים.
- מחברים אותו לארבעת הדפים בשורה אחת ב-`<head>`.
- כותבים את הכללים הראשונים: סלקטור אלמנט, מחלקה, מזהה, צאצא, תכונה ופסאודו-מחלקה.
- **האתר מקבל צבע בפעם הראשונה.**

</div>

<div dir="rtl" align="right">

## 🌍 למה זה ככה בעולם האמיתי

### ניסוי: מה קורה כשה-CSS נעלם

פתחו כל אתר שאתם אוהבים, `F12` ← Console, והדביקו:

</div>

```js
document.querySelectorAll('link[rel=stylesheet], style').forEach(el => el.remove());
```

<div dir="rtl" align="right">

האתר הפך לדף שחור-לבן עם קישורים כחולים – **בדיוק כמו האתר שלנו לפני השורה שנוסיף היום.**
כל המידע עדיין שם, כל הקישורים עובדים. CSS לא מוסיף תוכן; הוא מחליט איך הוא נראה.

זו גם הסיבה שהתחלנו מ-HTML: אתר שנשען על CSS כדי להיות **מובן** – שבור.

### למה קובץ חיצוני ולא `style=` על התג

יש שלוש דרכים לשלב CSS, ולכולן יש מקום – אבל רק אחת מהן נכונה לפרויקט הזה:

| הדרך | מתי משתמשים | הבעיה |
|-------|---------------|--------|
| `style="color: red"` על התג | תיקון נקודתי, או HTML של מייל | חוזר על עצמו, לא ניתן למחזור, ספציפיות ענקית |
| `<style>` ב-`<head>` | דף בודד, או CSS קריטי לטעינה מהירה | לא משותף בין דפים |
| **`<link>` לקובץ חיצוני** | **כל פרויקט אמיתי** | – |

יש לנו **ארבעה דפים**. עם `style=` היינו משנים צבע בארבעה מקומות. עם קובץ אחד –
מקום אחד, וגם הדפדפן שומר אותו במטמון ומוריד אותו פעם אחת לכל האתר.

### הרווח הוא אופרטור

הטעות שתחזור בכל שיעור:

| הסלקטור | מה הוא בוחר |
|-----------|---------------|
| `.site-header a` | קישור **בתוך** הכותרת (שני אלמנטים!) |
| `.site-header.a` | אלמנט אחד שיש לו **שתי המחלקות** |

הרווח אומר "בתוך". הצמדה אומרת "וגם".

</div>

## 🔨 שלב אחר שלב

### 1. יוצרים את הקובץ

</div>

```text
cafe-atid/
├── index.html
├── css/
│   └── style.css      ← חדש
└── images/
```

<div dir="rtl" align="right">

### 2. מחברים – שורה אחת בכל אחד מארבעת הדפים

</div>

```html
<head>
  ...
  <title>קפה עתיד – בית קפה שכונתי בתל אביב</title>
  <link rel="stylesheet" href="css/style.css">
</head>
```

<div dir="rtl" align="right">

**שכחתם את השורה באחד הדפים?** הדף הזה יישאר שחור-לבן ותחפשו באג ב-CSS.
הבדיקה הראשונה תמיד: `F12` ← Network ← לוודא ש-`style.css` נטען עם קוד 200.

### 3. אנטומיה של כלל

</div>

```css
h1, h2, h3 {          /* ← סלקטור: על מי זה חל */
  color: #4a2c17;     /* ← מאפיין: ערך; */
}                     /* ← אל תשכחו את הסוגר */
```

<div dir="rtl" align="right">

**נקודה-פסיק אחרי כל הצהרה.** אם שכחתם – ההצהרה **הבאה** נזרקת, לא הנוכחית.
זה הופך את החיפוש למבלבל: השורה שנשברה נראית תקינה לגמרי.

### 4. ששת הסלקטורים שכתבנו היום

</div>

```css
body            { }   /* אלמנט – כל <body> */
h1, h2, h3      { }   /* מקובץ – חוסך שכפול */
.site-header    { }   /* מחלקה – class="site-header" */
#main-nav       { }   /* מזהה – id="main-nav" */
.site-header a  { }   /* צאצא – <a> בתוך .site-header */
[aria-current="page"] { }  /* תכונה */
a:hover         { }   /* פסאודו-מחלקה – מצב */
```

<div dir="rtl" align="right">

**שימו לב לשניים האחרונים:**

`[aria-current="page"]` – בשלב 06 סימנו את הדף הנוכחי בתכונת נגישות.
עכשיו אנחנו **מעצבים לפי אותה תכונה**, בלי להוסיף `class` נוסף. סמנטיקה שמשלמת חזרה.

`a:hover` – זה לא בוחר אלמנט, זה בוחר **מצב** של אלמנט.

### 5. ירושה – מה עובר לילדים ומה לא

</div>

```css
body { color: #2b2b2b; font-family: system-ui, ...; }
```

<div dir="rtl" align="right">

כתבנו את זה **פעם אחת**, וכל הפסקאות, הרשימות והתאים בדף קיבלו את זה.
**מאפייני טקסט עוברים בירושה.** `background`, `border`, `padding`, `margin` – **לא**.

זו הסיבה ש-`body { background-color: #f5efe6 }` צובע את כל המסך, אבל לא צובע
כל אלמנט בנפרד: הרקע של ה-`body` פשוט נראה מאחורי כולם.

## 💻 הקוד המלא של השלב

`css/style.css` – הקובץ במלואו:

</div>

```css
/* ============================================================
   קפה עתיד – גיליון העיצוב של הכיתה
   שלב 08 · CSS מודול 1 – הקובץ הראשון וסלקטורים
   ============================================================ */

/* סלקטור אלמנט – חל על כל <body> בדף (יש אחד) */
body {
  font-family: system-ui, "Segoe UI", Arial, sans-serif;
  line-height: 1.7;
  color: #2b2b2b;
  background-color: #f5efe6;
  margin: 0;
}

/* סלקטור מקובץ – אותו כלל לשלוש כותרות */
h1, h2, h3 {
  color: #4a2c17;
}

a {
  color: #7b4b2a;
}

/* פסאודו-מחלקה: המצב של האלמנט, לא האלמנט עצמו */
a:hover {
  color: #a8541f;
}

/* סלקטור מחלקה */
.site-header {
  background-color: #4a2c17;
  padding: 12px 20px;
}

/* צאצא: קישור *בתוך* הכותרת. הרווח הוא אופרטור! */
.site-header a {
  color: #f5efe6;
}

/* סלקטור מזהה – יחיד בדף */
#main-nav ul {
  list-style: none;
  padding: 0;
}

/* סלקטור תכונה – בלי להוסיף class כלשהו ל-HTML */
[aria-current="page"] {
  text-decoration: underline;
  text-underline-offset: 4px;
}

.site-footer {
  background-color: #4a2c17;
  color: #f5efe6;
  padding: 20px;
}

.site-footer a {
  color: #e8d5b7;
}
```

<div dir="rtl" align="right">

## 👀 מה רואים במסך

- רקע קרם חם במקום לבן.
- **סרגל ניווט חום כהה** בראש הדף עם טקסט בהיר.
- כותרות בחום, קישורים בחום בהיר יותר שמשתנה במעבר עכבר.
- הנקודות השחורות של רשימת הניווט נעלמו (`list-style: none`).
- הפוטר חום כהה כמו הכותרת.

**זה עדיין לא יפה** – הכול צמוד לקצוות, אין מרווחים והכותרת נמרחת לרוחב.
מרווחים זה שלב 10, סידור זה שלב 12. אבל **זה כבר האתר שלנו, בצבעים שלנו.**

## ✋ אתגר לכיתה

1. הפכו את שם העסק בכותרת (`.logo`) לגדול יותר בעזרת סלקטור מחלקה.
2. צבעו **רק** את הקישורים שבתוך הפוטר בצבע `#e8d5b7` – בלי לגעת בשאר הקישורים.
3. **שאלת ספציפיות:** יש לנו `a { color: #7b4b2a }` וגם `.site-header a { color: #f5efe6 }`.
   באיזה צבע יהיה קישור בכותרת, ולמה?

</div>
</div>

<details dir="rtl">
<summary><b>💡 הצגת הפתרון</b></summary>

<div dir="rtl" align="right">

**1.** `.logo img { width: 180px; }` – או, אם רוצים טקסט, `.logo { font-size: 1.5rem; }`.

**2.** `.site-footer a { color: #e8d5b7; }` – זה כבר בקובץ. הרווח מגביל את הכלל
לקישורים שנמצאים **בתוך** הפוטר בלבד.

**3. בהיר (`#f5efe6`).** נספור ספציפיות בארבע עמודות `(inline, id, class, element)`:

| הכלל | inline | id | class | element | |
|-------|--------|----|----|---------|---|
| `a` | 0 | 0 | 0 | 1 | `0,0,0,1` |
| `.site-header a` | 0 | 0 | **1** | 1 | `0,0,1,1` |

משווים **עמודה-עמודה משמאל לימין ועוצרים בהכרעה הראשונה**:
inline שווה, id שווה, **class: 1 מול 0 → הוכרע**. הכלל השני מנצח.

לא סופרים "כמה סלקטורים יש" ולא מחברים למספר אחד – משווים עמודות.

</div>
</details>

## 🔍 טעויות שראינו בכיתה

| הטעות | מה קורה |
|--------|----------|
| `<link href="style.css">` והקובץ ב-`css/` | 404 שקט. הדף נטען בלי עיצוב |
| `.site-header a` נכתב `.site-header, a` | הפסיק אומר "וגם" – כל הקישורים בדף נצבעים |
| שכחת `;` בסוף הצהרה | ההצהרה **הבאה** מתבטלת |
| `class="site header"` (רווח) | אלו **שתי** מחלקות, ואף אחת לא `site-header` |
| שינוי CSS לא מופיע | רענון עם `Ctrl+Shift+R` – הדפדפן שמר את הקובץ הישן |

</div>
