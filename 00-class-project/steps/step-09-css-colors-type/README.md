## 🎯 מה מוסיפים היום

- קובעים **פלטת צבעים** אחת לכל האתר, ולומדים HEX מול `hsl()`.
- בוחרים שני פונטים: אחד לכותרות ואחד לגוף הטקסט – עם **מחסנית גיבוי**.
- מגדירים סולם גדלים ב-`rem` במקום מספרים אקראיים ב-`px`.
- מטפלים בבעיה ספציפית לעברית: **מספרים ומחירים בתוך טקסט RTL**.

</div>

<div dir="rtl" align="right">

## 🌍 למה זה ככה בעולם האמיתי

### שלוש דרכים לכתוב את אותו צבע

</div>

```css
color: #4a2c17;                 /* HEX  – מה שמעצב יתן לכם */
color: rgb(74 44 23);           /* RGB  – מה שהמסך באמת עושה */
color: hsl(26 53% 19%);         /* HSL  – מה שאדם מבין */
```

<div dir="rtl" align="right">

**למה HSL שווה את הלימוד:** רוצים את אותו חום, רק בהיר יותר? ב-HEX תנחשו.
ב-HSL תשנו מספר אחד – את ה-L:

</div>

```css
hsl(26 53% 19%)   /* החום של המותג */
hsl(26 53% 35%)   /* אותו חום בדיוק, בהיר יותר */
hsl(26 53% 92%)   /* אותו חום, כרקע עדין */
```

<div dir="rtl" align="right">

כך בונים פלטה שנראית שייכת לעצמה, במקום חמישה חומים שנבחרו בנפרד.

### מחסנית פונטים – למה לא כותבים שם אחד

</div>

```css
font-family: system-ui, "Segoe UI", Arial, sans-serif;
```

<div dir="rtl" align="right">

הדפדפן מנסה **משמאל לימין** ולוקח את הראשון שמותקן.

`system-ui` הוא הטריק הטוב ביותר: הוא אומר *"הפונט של מערכת ההפעלה"* –
ב-Windows זה Segoe UI, ב-Mac זה San Francisco, באנדרואיד זה Roboto.
התוצאה: האתר מרגיש מקומי בכל מכשיר, **ולא מוריד ולו בייט אחד**.

פונט מ-Google Fonts הוא 100–300KB לפני שהמשתמש ראה מילה. לפעמים זה שווה את זה.
לפעמים לא.

### `rem` מול `px` – למה זו שאלת נגישות

`1rem` = גודל הפונט הבסיסי של הדפדפן, ברירת מחדל 16px.

משתמש שמתקשה לקרוא נכנס להגדרות הדפדפן ומגדיל את הבסיס ל-20px.
- כתבתם ב-`rem` → **כל האתר גדל איתו.**
- כתבתם ב-`px` → **שום דבר לא קורה.** התעלמתם ממנו.

**הכלל בקורס:** `rem` לפונטים, `px` למסגרות ולפרטים קטנים.

### הבעיה שרק אתרים בעברית פוגשים

כתבו "הפוך – 13₪" בתוך פסקה בעברית. לפעמים המחיר יקפוץ, הסימן יעבור צד,
או "13" ייראה כמו "31" ליד סוגריים. זה **אלגוריתם ה-BiDi** של יוניקוד מנחש
לאיזה כיוון שייך כל תו.

הפתרון: לעטוף את המספר ולהצהיר עליו במפורש:

</div>

```css
.price {
  direction: ltr;
  unicode-bidi: embed;
  font-variant-numeric: tabular-nums;   /* כל ספרה באותו רוחב → מחירים מיושרים */
}
```

## 🔨 שלב אחר שלב

### 1. פלטה של חמישה צבעים, לא חמישה־עשר

| התפקיד | הצבע | איפה |
|---------|-------|-------|
| מותג כהה | `#4a2c17` | כותרת, פוטר, כותרות |
| מותג | `#7b4b2a` | קישורים, `h3` |
| הדגשה | `#c9a227` | תוויות, מצב פוקוס |
| רקע | `#f5efe6` | ה-`body` |
| טקסט | `#2b2b2b` | כל הטקסט |

**שחור מלא (`#000`) כמעט אף פעם לא נכון** – הניגודיות מול לבן קשה לעין.
`#2b2b2b` נראה שחור ומרגיש רך.

### 2. שני פונטים – לא יותר

</div>

```css
body      { font-family: system-ui, "Segoe UI", Arial, sans-serif; }
h1, h2, h3 { font-family: Georgia, "Times New Roman", serif; }
```

<div dir="rtl" align="right">

כותרות ב-serif, גוף ב-sans-serif. הניגוד הזה עושה חצי מהעבודה של "אתר מעוצב".

### 3. סולם גדלים

</div>

```css
h1 { font-size: 2.5rem; }
h2 { font-size: 1.75rem; }
h3 { font-size: 1.25rem; }
body { font-size: 1.0625rem; }   /* 17px */
```

<div dir="rtl" align="right">

המספרים לא אקראיים – כל אחד גדול מקודמו ביחס דומה. זה מה שיוצר היררכיה
שהעין קוראת בלי לחשוב.

**ולמה 17px ולא 16px?** בעברית האותיות נמוכות יותר מלטיניות באותו גודל נקודה.
פיקסל אחד נוסף עושה הבדל אמיתי בנוחות הקריאה.

### 4. `line-height` – המספר בלי יחידה

</div>

```css
body { line-height: 1.7; }   /* לא 1.7rem, לא 27px */
```

<div dir="rtl" align="right">

`1.7` = פי 1.7 מגודל הפונט **של האלמנט עצמו**. אם תכתבו `line-height: 27px`
בירושה, כותרת בגודל 40px תקבל גם היא 27px ותיראה דחוסה.

**טקסט בעברית צריך `line-height` נדיב** – 1.6–1.8. ניקוד וסופיות צריכים אוויר.

### 5. פסאודו-אלמנט ראשון

</div>

```css
::selection {
  background-color: #c9a227;
  color: #2b2b2b;
}
```

<div dir="rtl" align="right">

סמנו טקסט בעכבר – הסימון עכשיו בזהב של המותג ולא בכחול של המערכת.
פרט קטן, ומייד מרגיש מכוון.

## 💻 מה נוסף ל-`style.css` היום

</div>

```css
/* ============================================================
   שלב 09 · CSS מודול 2 – צבעים וטיפוגרפיה
   ============================================================ */

body {
  font-size: 1.0625rem;          /* 17px – נוח לקריאה בעברית */
  color: hsl(0, 0%, 17%);
}

h1, h2, h3 {
  font-family: Georgia, "Times New Roman", serif;
  line-height: 1.25;
  letter-spacing: -0.01em;
}

h1 { font-size: 2.5rem;  margin-bottom: 0.4em; }
h2 { font-size: 1.75rem; margin-top: 1.8em; }
h3 { font-size: 1.25rem; color: #7b4b2a; }

small,
.muted {
  color: #6b6257;
  font-size: 0.875rem;
}

blockquote {
  font-size: 1.15rem;
  font-style: italic;
  color: #4a2c17;
  border-right: 4px solid #c9a227;
}

blockquote footer {
  font-size: 0.9rem;
  font-style: normal;
  color: #6b6257;
}

/* פסאודו-אלמנט: הטקסט המסומן בעכבר */
::selection {
  background-color: #c9a227;
  color: #2b2b2b;
}

/* מספרי מחירים בספרות לטיניות – מיושרים גם בשורה בעברית */
.price {
  font-variant-numeric: tabular-nums;
  direction: ltr;
  unicode-bidi: embed;
}
```

<div dir="rtl" align="right">

## 👀 מה רואים במסך

- הכותרות הפכו ל-**serif** – מיד יש "אישיות" לאתר.
- הטקסט קצת גדול יותר ונושם יותר.
- הציטוט של נועה בגופן נטוי גדול עם **קו זהב בצד ימין**.
- סימון טקסט בעכבר → זהב.
- המחירים בתפריט מיושרים זה מתחת לזה במקום לרקוד.

## ✋ אתגר לכיתה

1. הוסיפו מחלקה `.badge` בצבע רקע `hsl(43 71% 47%)` ובדקו ב-DevTools
   מה ה-HEX המקביל.
2. שנו את גודל הפונט הבסיסי של הדפדפן ל-20px
   (Chrome ← הגדרות ← מראה ← גודל גופן) ורעננו. מה גדל ומה לא?
3. **בעיית BiDi:** כתבו בפסקה עברית `הגענו ל-(15) לקוחות`. בדקו איפה הסוגריים
   מופיעים. תקנו.

</div>
</div>

<details dir="rtl">
<summary><b>💡 הצגת הפתרון</b></summary>

<div dir="rtl" align="right">

**1.** `.badge { background-color: hsl(43 71% 47%); }` – ב-DevTools לוחצים על
ריבוע הצבע ליד הערך, ולוחצים על הכיתוב `HSL` כדי לעבור בין HEX/RGB/HSL.
זה `#c9a227` – בדיוק צבע ההדגשה שלנו.

**2.** כל מה שכתוב ב-`rem` גדל: הכותרות, הטקסט, המרווחים היחסיים.
מה שכתוב ב-`px` – המסגרות, ה-`border-radius`, רוחב הלוגו – **נשאר בדיוק אותו דבר**.

זה בדיוק מה שרוצים: הטקסט מתאים את עצמו למשתמש, הקישוט נשאר יציב.

**3.** הסוגר הפותח יופיע בצד הלא נכון, כי `(` ו-`)` הם תווים "ניטרליים"
והאלגוריתם מנחש. הפתרון – לעטוף במפורש:

`הגענו ל-<span class="price">(15)</span> לקוחות`

ה-`unicode-bidi: embed` + `direction: ltr` הופכים את הקטע לאי עצמאי שכיוונו ידוע.

</div>
</details>

## 🔍 טעויות שראינו בכיתה

| הטעות | מה קורה |
|--------|----------|
| `font-family: Assistant` בלי גיבוי | במחשב בלי הפונט – Times New Roman |
| `line-height: 27px` בירושה | כותרות גדולות נדחסות |
| הכול ב-`px` | הגדלת גופן בדפדפן לא עושה כלום |
| 12 גוונים של חום | האתר נראה "לא מסונכרן". פלטה = 5 צבעים |
| `color: #FFF` על רקע `#f5efe6` | ניגודיות 1.1:1 – בלתי קריא. בודקים ב-DevTools ← Contrast |
