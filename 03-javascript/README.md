# ⚡ חלק ג׳ – JavaScript

> **מצב:** 🚧 בבנייה – שלד התיקיות קיים, החומרים בהכנה.
> **היקף מומלץ:** 12 מפגשים · 48 שעות.

JavaScript הוא ה**התנהגות**: מה קורה כשלוחצים, מה משתנה, מאיפה מגיעים הנתונים.

## 🎯 מה התלמיד יודע לעשות בסוף

- לכתוב לוגיקה בסיסית: תנאים, לולאות, פונקציות, מבני נתונים.
- לשנות את הדף בתגובה לפעולות המשתמש.
- למשוך נתונים מ-API חיצוני ולהציג אותם.
- לשמור מצב בין רענוני דף.
- לנפות באגים בעזרת DevTools במקום לנחש.

## ℹ️ הערה על היקף

הקורס מלמד **צד לקוח בלבד**. אין Node.js, אין שרתים ואין SQL –
בסיסי נתונים נלמדים בקורס נפרד. מודול 12 עובד מול API ציבורי חינמי.
