## 🗂️ מבנה כל מודול

**כל נושא בדף המודול בנוי לפי אותו רצף קבוע:**

| הסימן | מה זה |
|--------|--------|
| 📖 | **ההסבר** – מה זה ולמה זה קיים |
| 🌍 | **מהעולם האמיתי** – איפה בדיוק רואים את זה באתרים מוכרים, ולמה זה משנה |
| 🔨 | **שלב אחר שלב** – בונים את המושג יחד, שורה-שורה |
| 💻 | **הקוד המלא** + מה יופיע על המסך |
| ✋ | **תרגול מיידי** – משימה קטנה עם פתרון מוסתר, מיד אחרי כל נושא |

**תרגילי הכיתה מופיעים במלואם בתוך דף המודול**, כך שאפשר ללמוד ולתרגל
מאותו מסך – עם קישור לקובץ השלד, לפתרון, ולסעיף התיאורטי שעליו התרגיל מתבסס.

## 🎯 למי הקורס מיועד

- תלמידים ללא רקע קודם בתכנות.
- הקורס מלמד **צד לקוח בלבד**. בסיסי נתונים ו-SQL נלמדים בקורס נפרד.
- לכן: אין כאן Node.js, אין שרתים ואין SQL. המודול על Fetch עובד מול API ציבורי חינמי.
