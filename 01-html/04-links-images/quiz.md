## חלק א׳ – אמריקאיות

**1.** איזו תכונה של `<a>` היא חובה?
- א. `target` &nbsp; ב. `href` &nbsp; ג. `rel` &nbsp; ד. `title`

**2.** מה משמעות `../` בנתיב?
- א. תיקייה אחת למטה &nbsp; ב. תיקייה אחת למעלה &nbsp; ג. שורש האתר &nbsp; ד. אותה תיקייה

**3.** למה חובה להוסיף `rel="noopener noreferrer"` ל-`target="_blank"`?
- א. כדי שהקישור ייפתח מהר יותר
- ב. למניעת פרצת אבטחה שבה הדף החדש יכול לשלוט בדף שלכם
- ג. כדי לשפר SEO
- ד. זה לא באמת נחוץ

**4.** מה יקרה אם נשמיט את `alt` לגמרי מ-`<img>`?
- א. התמונה לא תוצג
- ב. קורא מסך יקריא את שם הקובץ – חוויה גרועה
- ג. שגיאה שתעצור את הדף
- ד. שום דבר

**5.** מתי כותבים `alt=""` (ריק)?
- א. תמיד, כשלא בטוחים מה לכתוב
- ב. כשהתמונה דקורטיבית בלבד ואין לה ערך תוכני
- ג. כשהתמונה גדולה
- ד. אף פעם

**6.** איזה פורמט מתאים ביותר ללוגו וקטורי?
- א. JPG &nbsp; ב. GIF &nbsp; ג. SVG &nbsp; ד. BMP

**7.** מה עושה `loading="lazy"`?
- א. מאט את טעינת הדף
- ב. טוען את התמונה רק כשהמשתמש מתקרב אליה בגלילה
- ג. מקטין את התמונה
- ד. מוסיף אנימציה

**8.** נמצאים בקובץ `pages/contact.html`. מה הנתיב הנכון ל-`images/logo.png` שבשורש?
- א. `images/logo.png`
- ב. `../images/logo.png`
- ג. `../../images/logo.png`
- ד. `/pages/images/logo.png`

**9.** מה תפקיד `<figcaption>`?
- א. להגדיל את התמונה
- ב. לספק כיתוב שקשור סמנטית לתמונה שבתוך `<figure>`
- ג. להחליף את `alt`
- ד. ליצור קישור

**10.** באיזו תגית משתמשים כדי להציג תמונה **שונה לגמרי** בנייד ובדסקטופ?
- א. `srcset` &nbsp; ב. `<picture>` &nbsp; ג. `sizes` &nbsp; ד. `media`

## חלק ג׳ – פתוחות

**16.** הסבירו למה `alt` הוא התכונה החשובה ביותר ב-`<img>`. פרטו לפחות 3 קהלים/מצבים שבהם היא קריטית.

**17.** כתבו `alt` טוב לכל תמונה, והסבירו את בחירתכם:
- א. תמונת פרופיל של מנכ״ל בדף "אודות"
- ב. קו מפריד דקורטיבי
- ג. לוגו שהוא קישור לדף הבית
- ד. גרף עמודות של מכירות

**18.** מה ההבדל בין `srcset` ל-`<picture>`? מתי תשתמשו בכל אחד?

**19.** כתבו קטע HTML של תפריט ניווט לאתר עם 4 דפים, כאשר הקובץ הנוכחי נמצא בתיקייה `pages/`. הדפים: `index.html` ו-`about.html` בשורש, `contact.html` ו-`faq.html` בתוך `pages/`.

**20.** בנו כרטיס מוצר שמכיל: תמונה עם כיתוב, שם המוצר ככותרת, קישור "פרטים נוספים" שנפתח באותה לשונית, וקישור "שתפו במייל" שפותח מייל עם נושא מוכן.
