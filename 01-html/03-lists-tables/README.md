# מודול 3 – רשימות וטבלאות

[⬅ המודול הקודם](../02-text-structure/) | [תוכן העניינים](../../README.md) | [המודול הבא: קישורים ותמונות ➡](../04-links-images/)

## 🎯 מטרות המודול

1. לבנות שלושה סוגי רשימות ולדעת מתי משתמשים בכל אחת.
2. לקנן רשימות זו בתוך זו.
3. לבנות טבלה תקינה עם `thead`, `tbody`, `tfoot`.
4. למזג תאים בעזרת `colspan` ו-`rowspan`.
5. להבין מתי **אסור** להשתמש בטבלה.

---

## 1. רשימה לא מסודרת – `<ul>`

Unordered List – פריטים ללא סדר חשוב. מוצגת עם נקודות.

</div>

```html
<ul>
  <li>חלב</li>
  <li>לחם</li>
  <li>ביצים</li>
</ul>
```

<div dir="rtl" align="right">

תוצאה:
- חלב
- לחם
- ביצים

---

## 2. רשימה מסודרת – `<ol>`

Ordered List – **הסדר משמעותי**. מוצגת עם מספרים.

</div>

```html
<ol>
  <li>לחמם את התנור ל-180 מעלות</li>
  <li>לערבב את החומרים היבשים</li>
  <li>להוסיף את הביצים</li>
  <li>לאפות 25 דקות</li>
</ol>
```

<div dir="rtl" align="right">

### תכונות של `<ol>`

| תכונה | ערכים | דוגמה |
|--------|--------|--------|
| `type` | `1` `A` `a` `I` `i` | `<ol type="A">` → A, B, C |
| `start` | מספר | `<ol start="5">` → מתחיל מ-5 |
| `reversed` | ללא ערך | `<ol reversed>` → סופר אחורה |

</div>

```html
<ol type="A">
  <li>אפשרות ראשונה</li>
  <li>אפשרות שנייה</li>
</ol>

<ol start="10">
  <li>פריט מספר 10</li>
  <li>פריט מספר 11</li>
</ol>
```

<div dir="rtl" align="right">

---

## 3. רשימת הגדרות – `<dl>`

Description List – זוגות של **מונח + הגדרה**. מושלמת למילון מונחים או שאלות ותשובות.

</div>

```html
<dl>
  <dt>HTML</dt>
  <dd>שפת סימון שמגדירה את מבנה הדף ותוכנו.</dd>

  <dt>CSS</dt>
  <dd>שפת עיצוב שקובעת איך הדף ייראה.</dd>

  <dt>JavaScript</dt>
  <dd>שפת תכנות שמוסיפה התנהגות ואינטראקטיביות.</dd>
</dl>
```

<div dir="rtl" align="right">

| תגית | פירוש | תפקיד |
|-------|--------|--------|
| `<dl>` | Description List | המיכל |
| `<dt>` | Description Term | המונח |
| `<dd>` | Description Details | ההגדרה |

> 💡 מונח אחד יכול לקבל כמה `<dd>`, וכמה `<dt>` יכולים לחלוק `<dd>` אחד.

---

## 4. רשימות מקוננות

כדי לקנן רשימה, שמים את ה-`<ul>`/`<ol>` הפנימי **בתוך `<li>`**, לא בין פריטים.

</div>

```html
<!-- ✅ נכון -->
<ul>
  <li>פירות
    <ul>
      <li>תפוח</li>
      <li>בננה</li>
    </ul>
  </li>
  <li>ירקות</li>
</ul>

<!-- ❌ שגוי – הרשימה הפנימית מחוץ ל-li -->
<ul>
  <li>פירות</li>
  <ul>
    <li>תפוח</li>
  </ul>
</ul>
```

<div dir="rtl" align="right">

---

## 5. טבלאות – מבנה בסיסי

טבלה נבנית **שורה אחר שורה**, ובכל שורה תאים.

</div>

```html
<table>
  <tr>
    <th>שם</th>
    <th>גיל</th>
    <th>עיר</th>
  </tr>
  <tr>
    <td>דנה</td>
    <td>28</td>
    <td>תל אביב</td>
  </tr>
  <tr>
    <td>יוסי</td>
    <td>34</td>
    <td>חיפה</td>
  </tr>
</table>
```

<div dir="rtl" align="right">

| תגית | פירוש | תפקיד |
|-------|--------|--------|
| `<table>` | Table | המיכל של כל הטבלה |
| `<tr>` | Table Row | שורה |
| `<th>` | Table Header | תא כותרת (מודגש וממורכז) |
| `<td>` | Table Data | תא נתונים רגיל |

---

## 6. טבלה מלאה ותקנית

טבלה מקצועית מחולקת ל-3 אזורים ומקבלת כותרת:

</div>

```html
<table>
  <caption>דוח מכירות רבעוני</caption>

  <thead>
    <tr>
      <th>מוצר</th>
      <th>כמות</th>
      <th>מחיר</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>מקלדת</td>
      <td>120</td>
      <td>150 ₪</td>
    </tr>
    <tr>
      <td>עכבר</td>
      <td>200</td>
      <td>80 ₪</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <th>סה״כ</th>
      <td>320</td>
      <td>34,000 ₪</td>
    </tr>
  </tfoot>
</table>
```

<div dir="rtl" align="right">

| תגית | תפקיד | למה חשוב |
|-------|--------|-----------|
| `<caption>` | כותרת הטבלה | חובה לנגישות. חייבת להיות הראשונה בתוך `<table>`. |
| `<thead>` | אזור הכותרות | הדפדפן חוזר עליו בהדפסת טבלה ארוכה. |
| `<tbody>` | גוף הנתונים | ניתן לגלול בנפרד. |
| `<tfoot>` | שורת סיכום | סיכומים וסה״כ. |

### נגישות בטבלאות – `scope`

</div>

```html
<th scope="col">מוצר</th>   <!-- כותרת של עמודה -->
<th scope="row">מקלדת</th>  <!-- כותרת של שורה -->
```

<div dir="rtl" align="right">

זה מאפשר לקורא מסך להכריז "מוצר: מקלדת, כמות: 120" במקום לקרוא מספרים מנותקים.

---

## 7. מיזוג תאים – `colspan` ו-`rowspan`

</div>

```html
<table>
  <tr>
    <th colspan="2">פרטים אישיים</th>   <!-- תא שתופס 2 עמודות -->
  </tr>
  <tr>
    <td>שם</td>
    <td>דנה</td>
  </tr>
</table>
```

<div dir="rtl" align="right">

</div>

```
colspan="3"  →  ┌──────────────────┐
                │  תא אחד רחב      │
                ├──────┬─────┬─────┤
                │      │     │     │
                └──────┴─────┴─────┘

rowspan="2"  →  ┌──────┬─────┐
                │      │     │
                │ תא   ├─────┤
                │ גבוה │     │
                └──────┴─────┘
```

```html
<table>
  <tr>
    <td rowspan="2">ראשון-שני</td>   <!-- תא שתופס 2 שורות -->
    <td>08:00</td>
  </tr>
  <tr>
    <td>10:00</td>
  </tr>
</table>
```

<div dir="rtl" align="right">

> ⚠️ **כלל ספירה:** כשמשתמשים ב-`colspan="2"`, בשורה הזו יש **תא אחד פחות**. שכחה לכך היא הסיבה מספר 1 לטבלה "שבורה".

---

## 8. מתי **לא** להשתמש בטבלה

בשנות ה-90 בנו את פריסת האתר כולו בטבלאות. **אל תעשו זאת.**

| שימוש | מותר? |
|--------|--------|
| הצגת **נתונים טבלאיים** (מחירון, לוח זמנים, ציונים) | ✅ כן |
| פריסת עמודות באתר | ❌ לא – השתמשו ב-Flexbox או Grid |
| יישור אלמנטים | ❌ לא – CSS |
| גלריית תמונות | ❌ לא – Grid |

**למה זה מזיק?** קורא מסך מכריז "טבלה בת 5 שורות ו-3 עמודות" ומנסה לקרוא נתונים – מה שהופך אתר שבנוי בטבלאות לבלתי שמיש עבור עיוורים.

| קטגוריה | תגיות |
|----------|--------|
| רשימות | `<ul>` `<ol>` `<li>` `<dl>` `<dt>` `<dd>` |
| טבלה – מבנה | `<table>` `<tr>` `<th>` `<td>` |
| טבלה – אזורים | `<caption>` `<thead>` `<tbody>` `<tfoot>` |
| טבלה – מיזוג | `colspan` `rowspan` |
| טבלה – נגישות | `scope="col"` `scope="row"` |
