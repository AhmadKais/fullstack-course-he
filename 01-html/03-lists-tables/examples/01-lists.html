1. רשימה לא מסודרת (ul) – הסדר לא משנה

רשימת קניות: לא משנה מה נקנה קודם.

  • חלב
  • לחם
  • ביצים
  • גבינה צהובה

2. רשימה מסודרת (ol) – הסדר קריטי

מתכון לעוגת שוקולד: שינוי הסדר יהרוס את העוגה.

  1. לחמם את התנור ל-180 מעלות
  2. לערבב קמח, סוכר ואבקת קקאו
  3. להוסיף 3 ביצים ולערבב
  4. לשפוך לתבנית משומנת
  5. לאפות 25 דקות

וריאציות של ol

עם אותיות – type="A":

  1. אפשרות ראשונה
  2. אפשרות שנייה
  3. אפשרות שלישית

עם ספרות רומיות – type="I":

  1. פרק ראשון
  2. פרק שני

מתחיל ממספר אחר – start="10":

  1. שלב עשירי
  2. שלב אחד-עשר

בסדר הפוך – reversed:

  1. מקום ראשון
  2. מקום שני
  3. מקום שלישי

3. רשימת הגדרות (dl) – מונח והסבר

HTML
שפת סימון שמגדירה את מבנה הדף ואת תוכנו.
CSS
שפת עיצוב שקובעת איך הדף נראה: צבעים, מרווחים ופריסה.
JavaScript
שפת תכנות שרצה בדפדפן ומוסיפה התנהגות ואינטראקטיביות.
DOM
ייצוג הדף כעץ אובייקטים.
הממשק שדרכו JavaScript משנה את הדף.
