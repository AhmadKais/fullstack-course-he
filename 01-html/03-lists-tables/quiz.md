## חלק א׳ – אמריקאיות

**1.** באיזו רשימה נשתמש למתכון עוגה?
- א. `<ul>` &nbsp; ב. `<ol>` &nbsp; ג. `<dl>` &nbsp; ד. `<table>`

**2.** מה מייצגות התגיות `<dt>` ו-`<dd>`?
- א. Data Table ו-Data Definition
- ב. Description Term ו-Description Details
- ג. Div Type ו-Div Data
- ד. Document Title ו-Document Data

**3.** איפה צריך למקם רשימה מקוננת?
- א. אחרי ה-`</li>` &nbsp; ב. בתוך ה-`<li>` &nbsp; ג. בתוך ה-`<ul>` ישירות &nbsp; ד. לא משנה

**4.** מה ההבדל בין `<th>` ל-`<td>`?
- א. `<th>` תא כותרת עם משמעות סמנטית, `<td>` תא נתונים רגיל
- ב. `<th>` גדול יותר
- ג. `<td>` הוא לכותרות
- ד. אין הבדל

**5.** איזו תגית חייבת להיות **הראשונה** בתוך `<table>`?
- א. `<thead>` &nbsp; ב. `<tr>` &nbsp; ג. `<caption>` &nbsp; ד. `<tbody>`

**6.** מה עושה `colspan="3"`?
- א. יוצר 3 עמודות חדשות
- ב. התא נמתח על פני 3 עמודות
- ג. התא נמתח על פני 3 שורות
- ד. מוחק 3 תאים

**7.** בשורה שיש בה תא עם `colspan="2"` בטבלה בת 4 עמודות, כמה תאים ייכתבו בקוד?
- א. 4 &nbsp; ב. 3 &nbsp; ג. 2 &nbsp; ד. 5

**8.** מה תפקיד התכונה `scope`?
- א. לקבוע את רוחב התא
- ב. להודיע לקורא מסך אם הכותרת שייכת לעמודה או לשורה
- ג. למזג תאים
- ד. לצבוע את התא

**9.** מתי **אסור** להשתמש בטבלה?
- א. להצגת לוח זמנים
- ב. להצגת מחירון
- ג. לפריסת אזורי הדף (תפריט, תוכן, כותרת תחתונה)
- ד. להצגת ציונים

**10.** מה עושה `<ol start="5">`?
- א. מציג 5 פריטים &nbsp; ב. מתחיל את המספור מ-5 &nbsp; ג. מזיז 5 פיקסלים &nbsp; ד. שגיאה
