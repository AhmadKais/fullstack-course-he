ולידציה מובנית של הדפדפן

כל הבדיקות בדף הזה נעשות בלי שורת JavaScript אחת. נסו לשלוח את הטופס עם ערכים שגויים.

🔒 אזהרה קריטית

ולידציה בצד הלקוח היא נוחות למשתמש בלבד, ולא אבטחה. כל אחד יכול לפתוח את כלי המפתחים, למחוק את התכונה required, ולשלוח מה שירצה. אפשר גם לשלוח בקשה לשרת בלי דפדפן בכלל.

הבדיקה האמיתית תמיד נעשית בשרת. זה נכון גם לגבי מסד הנתונים שתלמדו בקורס ה-SQL.

איך מבטלים ולידציה זמנית?

לצורכי פיתוח, אפשר להוסיף novalidate לתגית ה-form: 

<form action="" method="post" novalidate>

הדפדפן יפסיק לבדוק, והטופס יישלח כמו שהוא.
