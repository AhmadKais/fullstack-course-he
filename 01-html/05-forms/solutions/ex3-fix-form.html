טופס הרשמה לניוזלטר – מתוקן

תוקן: הוסף name="fullname", וה-for הותאם ל-id.

תוקן: type="email" נותן ולידציה ומקלדת מותאמת בנייד.

תוקן: type="number" עם טווח הגיוני.

תדירות קבלת עדכונים

תוקן: לכל שלושת הכפתורים אותו name="frequency".

תוקן: כל option קיבל value. בלעדיו נשלח הטקסט המוצג – שביר ותלוי שפה.

תוקן: value הוחלף ב-placeholder. ל-textarea הערך נכתב בין התגיות.

תוקן: נוסף required.

תוקן: נוסף type="reset". זו טעות נפוצה מאוד – ברירת המחדל של <button> בתוך טופס היא submit.

סיכום 8 השגיאות

  1. שדה ללא name + label for לא תואם ל-id
  2. type="text" במקום type="email"
  3. type="text" במקום type="number"
  4. קבוצת רדיו עם name שונה בכל כפתור
  5. option ללא value
  6. textarea עם תכונת value (לא קיימת)
  7. תיבת סימון חובה ללא required
  8. button ללא type – שולח את הטופס במקום לאפס
