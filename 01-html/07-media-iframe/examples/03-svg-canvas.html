SVG בפועל

SVG נכתב ישירות בתוך ה-HTML, בדיוק כמו כל תגית אחרת:

למה SVG כל כך שימושי?

  • חד בכל גודל – אותו קובץ לאייקון של 16px ולבאנר של 2000px.
  • קובץ זעיר – האייקון למעלה שוקל פחות מ-300 בתים.
  • ניתן לעיצוב ב-CSS – רחפו על הלב ותראו. עם תמונת PNG זה בלתי אפשרי.
  • נגיש – role="img" + aria-label, או תגית <title> בתוך ה-SVG.

Canvas בפועל

<canvas> הוא בד ציור ריק לגמרי. בלי JavaScript לא יופיע בו כלום:

הדפדפן שלך אינו תומך ב-canvas.

הציור שלמעלה נוצר בקוד הבא (נלמד JavaScript בחלק ג׳ של הקורס):

const canvas = document.getElementById("demoCanvas");
const ctx = canvas.getContext("2d");

ctx.fillStyle = "#f0b429";
ctx.fillRect(20, 20, 80, 60);

ctx.fillStyle = "#2b6cb0";
ctx.beginPath();
ctx.arc(180, 50, 35, 0, Math.PI * 2);
ctx.fill();

📌 המסקנה לקורס

בקורס הזה נשתמש ב-SVG לאייקונים וללוגו. <canvas> דורש שליטה ב-JavaScript ומתאים למשחקים ולוויזואליזציות כבדות – מעבר להיקף הקורס.

כלל אצבע: אם אתם יכולים לתאר את הצורה במילים ("עיגול כחול ברדיוס 50") – זה SVG. אם אתם צריכים לצייר עשרות אלפי פיקסלים 60 פעם בשנייה – זה Canvas.
