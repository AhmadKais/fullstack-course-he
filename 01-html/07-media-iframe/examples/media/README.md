# תיקיית מדיה

בתיקייה זו נמצאים קובצי הכתוביות (`.vtt`) לדוגמאות המודול.

**קובצי וידאו ואודיו אינם כלולים בריפו** כדי לא לנפח אותו.
כדי להריץ את הדוגמאות עם מדיה אמיתית:

1. הורידו סרטון קצר וקובץ אודיו קצר.
2. שמרו אותם כאן בשמות: `sample.mp4`, `sample.webm`, `sample.mp3`.
3. רעננו את הדוגמאות.

**מקורות חינמיים (ללא זכויות יוצרים):**
- וידאו: <https://pixabay.com/videos/> · <https://www.pexels.com/videos/>
- אודיו: <https://pixabay.com/music/> · <https://freesound.org/>

בלי הקבצים, הדוגמאות עדיין יעבדו ויציגו את **תוכן הגיבוי** – וזו כשלעצמה
הדגמה חשובה של מה קורה כשהמדיה אינה זמינה.
