## חלק א׳ – אמריקאיות

**1.** כמה תגיות `<main>` מותר שיהיו בדף?
- א. אחת &nbsp; ב. שתיים &nbsp; ג. כמה שרוצים &nbsp; ד. אף אחת

**2.** מתי נשתמש ב-`<article>` ולא ב-`<section>`?
- א. כשהתוכן ארוך
- ב. כשהתוכן הגיוני בפני עצמו גם מחוץ להקשר של הדף
- ג. כשיש תמונות
- ד. אין הבדל

**3.** מה **חייב** להיות בתוך `<section>`?
- א. תמונה &nbsp; ב. כותרת &nbsp; ג. קישור &nbsp; ד. טופס

**4.** מה תפקיד קישור הדילוג (skip link)?
- א. לדלג לעמוד הבא
- ב. לאפשר למשתמש מקלדת לדלג על התפריט ולהגיע ישר לתוכן
- ג. להאיץ את טעינת הדף
- ד. לשפר SEO

**5.** מהו הכלל הראשון של ARIA?
- א. תמיד להשתמש ב-ARIA
- ב. אל תשתמשו ב-ARIA אם יש תגית HTML שעושה את זה
- ג. ARIA מיועד רק לטפסים
- ד. ARIA מחליף תגיות סמנטיות

**6.** באיזו תכונה משתמשות תגיות Open Graph?
- א. `name` &nbsp; ב. `property` &nbsp; ג. `content` בלבד &nbsp; ד. `rel`

**7.** מה הבעיה עם `*:focus { outline: none; }`?
- א. זה מאט את הדף
- ב. זה מוחק את סימון המיקוד והופך ניווט במקלדת לבלתי אפשרי
- ג. זה עובד רק בכרום
- ד. אין בעיה

**8.** באיזו תגית נשתמש לפרטי הקשר בתחתית האתר?
- א. `<div>` &nbsp; ב. `<contact>` &nbsp; ג. `<address>` &nbsp; ד. `<info>`

**9.** מה עושה `aria-hidden="true"`?
- א. מסתיר את האלמנט מהמסך
- ב. מסתיר את האלמנט מקוראי מסך בלבד
- ג. מוחק את האלמנט
- ד. הופך אותו לשקוף

**10.** מה האורך המומלץ ל-`<meta name="description">`?
- א. 20–30 תווים &nbsp; ב. 50–60 תווים &nbsp; ג. 150–160 תווים &nbsp; ד. 500 תווים

- ג. "קרא גם" בסרגל הצד
- ד. הפסקה עם שם המחבר ותאריך בתוך הפוסט
- ה. עטיפה שמרכזת את התוכן
