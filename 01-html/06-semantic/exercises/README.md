# 🏋️ תרגילים – מודול 6: HTML סמנטי

---

## תרגיל 1 – המרה מ-div לסמנטי 🟢

**קובץ:** `ex1-convert-to-semantic.html`

בקובץ יש דף שבנוי כולו מ-`<div>`. המירו כל `<div>` לתגית הסמנטית הנכונה.
**אל תשנו את התוכן** – רק את התגיות.

בסוף הקובץ, כתבו בהערה את הטבלה: איזה `div` הפך לאיזו תגית, ולמה.

---

## תרגיל 2 – שלד דף מלא 🟢

**קובץ:** `ex2-page-skeleton.html`

בנו מאפס שלד של דף חדשות, הכולל:

1. קישור דילוג לתוכן.
2. `<header>` עם `<h1>` ו-`<nav>` (5 קישורים ברשימה).
3. `<main>` עם 3 אלמנטי `<article>`, כל אחד עם `<header>` פנימי, `<h2>`, `<time>` ו-2 פסקאות.
4. `<aside>` עם "הכי נקראים" – רשימה של 4 כותרות.
5. `<footer>` עם `<address>` ושורת זכויות יוצרים.
6. `<head>` מלא: charset, viewport, description, title.

---

## תרגיל 3 – article מול section מול div 🟡

**קובץ:** `ex3-article-section.html`

לפניכם 8 תיאורי תוכן. לכל אחד, כתבו איזו תגית מתאימה (`<article>` / `<section>` / `<div>`) ו**נמקו** בהערה:

1. פוסט בודד בבלוג
2. אזור "אודותינו" בדף הבית
3. עטיפה שנועדה רק למרכז את התוכן ב-CSS
4. תגובה של משתמש מתחת לפוסט
5. פרק 3 בתוך מדריך ארוך
6. כרטיס מוצר בחנות אונליין
7. אזור "שאלות נפוצות" בדף
8. שורה שמכילה 3 עמודות לצורכי פריסה

לאחר מכן – **ממשו** את הדף בפועל עם התגיות שבחרתם.

---

## תרגיל 4 – תיקון נגישות 🟡

**קובץ:** `ex4-fix-accessibility.html`

בקובץ יש דף עם **10 בעיות נגישות**. מצאו, תקנו, וכתבו בהערה מה הייתה הבעיה.

רמזים למה לחפש: `lang`, `alt`, היררכיית כותרות, `<label>`, טקסט קישור,
`div` שמתפקד ככפתור, `outline: none`, `<main>` חסר, טבלה לפריסה, כפתור אייקון בלי שם.

**בדיקה:** הריצו Lighthouse (F12 ← Lighthouse ← Accessibility). היעד: ציון 100.

## תרגיל 5 – אתגר: דף אתר מלא ⭐

**קובץ:** `ex5-complete-page.html`

בנו דף בית מלא לעסק לבחירתכם (מספרה, מסעדה, סטודיו יוגה), הכולל:

**מבנה:**
- [ ] קישור דילוג
- [ ] `<header>` + `<nav>` עם `aria-label`
- [ ] `<main>` יחיד
- [ ] לפחות 3 `<section>` בעלי כותרות
- [ ] לפחות 2 `<article>`
- [ ] `<aside>`
- [ ] `<footer>` עם `<address>`
- [ ] `<figure>` + `<figcaption>`
- [ ] `<details>`/`<summary>` לשאלות נפוצות (לפחות 3)
- [ ] `<time>` עם `datetime`
- [ ] טופס יצירת קשר נגיש

**נגישות:**
- [ ] `lang` ו-`dir` תקינים
- [ ] היררכיית כותרות ללא דילוגים
- [ ] `alt` לכל תמונה
- [ ] `<label>` לכל שדה
- [ ] טקסט קישור משמעותי
- [ ] `aria-label` לכפתור אייקון

**SEO:**
- [ ] `<title>` ייחודי (50–60 תווים)
- [ ] `meta description` (150–160 תווים)
- [ ] 4 תגיות Open Graph לפחות
- [ ] `link canonical`

**יעדים:** Lighthouse – נגישות 100, SEO 100. `validator.w3.org` – 0 שגיאות.
