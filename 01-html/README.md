## 🎯 מה התלמיד יודע לעשות בסוף

- לכתוב מסמך HTML5 תקין מאפס, בעברית, עם `dir="rtl"`.
- לבחור את התגית **הנכונה** לפי המשמעות – לא לפי איך זה נראה.
- לבנות טופס הרשמה מלא עם ולידציה, בלי שורת JavaScript אחת.
- לבנות אתר מרובה-עמודים עם קישורים יחסיים שעובדים.
- לזהות ולתקן בעיות נגישות בסיסיות.
