## חלק א׳ – שאלות אמריקאיות (10 נקודות)

**1.** מה המשמעות של ראשי התיבות HTML?

- א. High Text Machine Language
- ב. HyperText Markup Language
- ג. HyperText Making Language
- ד. Home Tool Markup Language

**2.** איזו תגית מכילה את התוכן שהמשתמש רואה על המסך?

- א. `<head>`
- ב. `<title>`
- ג. `<body>`
- ד. `<meta>`

**3.** מה יקרה אם נשכח את `<meta charset="UTF-8">` בדף בעברית?

- א. הדף לא ייטען בכלל
- ב. העברית עלולה להופיע כתווים משובשים
- ג. הדף ייטען לאט יותר
- ד. שום דבר, זו תגית מיותרת

**4.** איזו מהתגיות הבאות היא **ריקה** (ללא תגית סוגרת)?

- א. `<p>`
- ב. `<div>`
- ג. `<br>`
- ד. `<h1>`

**5.** מה ההבדל בין `id` ל-`class`?

- א. אין הבדל, שניהם זהים
- ב. `id` ייחודי לאלמנט אחד, `class` יכול לחזור על כמה אלמנטים
- ג. `class` ייחודי, `id` יכול לחזור
- ד. `id` עובד רק בכותרות

**6.** איזה קינון הוא **תקין**?

- א. `<p><strong>טקסט</p></strong>`
- ב. `<strong><p>טקסט</strong></p>`
- ג. `<p><strong>טקסט</strong></p>`
- ד. `<p><strong>טקסט<p></strong>`

**7.** מה תפקיד התכונה `dir="rtl"`?

- א. מגדירה את שפת הדף
- ב. מגדירה כיוון כתיבה מימין לשמאל
- ג. מגדירה את הכותרת
- ד. מגדירה את גודל הפונט

**8.** היכן מופיע התוכן של תגית `<title>`?

- א. בראש הדף בגופן גדול
- ב. בלשונית הדפדפן ובתוצאות החיפוש
- ג. בתחתית הדף
- ד. הוא לא מופיע בשום מקום

**9.** מהי הצהרת `<!DOCTYPE html>`?

- א. תגית HTML רגילה
- ב. הערה
- ג. הצהרה שמודיעה לדפדפן שזהו מסמך HTML5
- ד. תכונה של תגית `<html>`

**10.** מה יוצג בדפדפן מהקוד הבא?

</div>

```html
<p>שורה
ראשונה</p>
```

<div dir="rtl" align="right">

- א. שתי שורות נפרדות
- ב. שורה אחת: "שורה ראשונה"
- ג. שגיאה
- ד. רק המילה "שורה"

## חלק ג׳ – שאלות פתוחות (10 נקודות)

**16.** הסבירו במילים שלכם את התהליך שקורה מרגע שהמשתמש מקליד כתובת בדפדפן ועד שהדף מוצג. השתמשו במונחים: לקוח, שרת, בקשה, תשובה, רינדור.

**17.** מהו ההבדל בתפקיד בין `<head>` ל-`<body>`? תנו שתי דוגמאות לתגיות שנמצאות בכל אחד מהם.

**18.** מצאו את 3 השגיאות בקוד הבא וכתבו את הגרסה המתוקנת:

</div>

```html
<html lang="he">
<head>
  <title>הדף שלי
</head>
<body>
  <h1>ברוכים הבאים</h2>
</body>
</html>
```
