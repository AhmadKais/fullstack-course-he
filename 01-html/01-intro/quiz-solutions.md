## חלק ג׳ – שאלות פתוחות

### 16. תהליך טעינת דף

**תשובה לדוגמה:**

1. המשתמש מקליד כתובת (URL) בדפדפן. הדפדפן הוא ה**לקוח (Client)**.
2. הדפדפן שולח **בקשה (Request)** בפרוטוקול HTTP אל ה**שרת (Server)** שמאחסן את האתר.
3. השרת מאתר את הקבצים המבוקשים ומחזיר **תשובה (Response)** שמכילה את קובץ ה-HTML.
4. הדפדפן קורא את ה-HTML, ותוך כדי כך מבקש גם את הקבצים הנוספים שמוזכרים בו – CSS, JavaScript, תמונות.
5. הדפדפן מבצע **רינדור (Rendering)**: הופך את הקוד לעץ אלמנטים, מחשב את העיצוב, ומצייר את התוצאה על המסך.

**נקודות לניקוד מלא:** אזכור של לקוח, שרת, בקשה, תשובה, רינדור.

### 17. ההבדל בין head ל-body

| | `<head>` | `<body>` |
|---|----------|-----------|
| **תפקיד** | מידע **על** הדף (מטא-מידע) | התוכן ש**נראה** למשתמש |
| **נראה למשתמש?** | לא (למעט `<title>` בלשונית) | כן |
| **דוגמאות** | `<title>`, `<meta>`, `<link>` | `<h1>`, `<p>`, `<img>`, `<a>` |

**דגש:** תוכן שנכתב בטעות בתוך `<head>` פשוט לא יופיע על המסך – זו טעות נפוצה מאוד.

---

### 18. תיקון הקוד

**השגיאות:**

1. חסרה שורת `<!DOCTYPE html>`.
2. תגית `<title>` לא נסגרה ב-`</title>`.
3. `<h1>` נסגרה בטעות עם `</h2>`.

**בונוס:** חסרים גם `dir="rtl"` ו-`<meta charset="UTF-8">` – בלעדיהם דף בעברית לא ייראה נכון.

**הגרסה המתוקנת:**

</div>

```html
<!DOCTYPE html>
<html lang="he" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>הדף שלי</title>
</head>
<body>
  <h1>ברוכים הבאים</h1>
</body>
</html>
```

### 19. בעיית טקסט מעורב

**הבעיה:** בתוך פסקה עם `dir="rtl"`, הדפדפן מיישר את כיוון הקריאה לימין. מספרי טלפון וכתובות מייל הם טקסט לועזי (LTR), וכשהם צמודים לסימני פיסוק או נמצאים בסוף משפט, סדר התווים עלול להיראות הפוך או שגוי – למשל `03-1234567` שמוצג כ-`1234567-03`.

**הפתרון:** לעטוף כל קטע לועזי בתגית `<span>` עם `dir="ltr"`, שמכריזה על "אי" של כיוון שמאל-לימין בתוך הטקסט העברי.

**הקוד המתוקן:**

</div>

```html
<p>
  צרו קשר בטלפון
  <span dir="ltr">03-1234567</span>
  או במייל
  <span dir="ltr">info@site.com</span>
</p>
```

### 20. מסמך מינימלי תקין

</div>

```html
<!DOCTYPE html>
<html lang="he" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>הדף שלי</title>
</head>
<body>
  <h1>שלום עולם</h1>
  <p>זו הפסקה הראשונה בדף.</p>
</body>
</html>
```
