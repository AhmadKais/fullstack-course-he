## 🎯 מטרות המודול

1. לבנות היררכיית כותרות נכונה.
2. להכיר את כל תגיות עיצוב הטקסט ומתי משתמשים בכל אחת.
3. להבין את ההבדל בין תגית **סמנטית** לתגית **ויזואלית**.
4. לעבוד עם ישויות (Entities) ותווים מיוחדים.
5. להציג טקסט מעוצב מראש וקוד.

---

## 1. כותרות (Headings)

ל-HTML יש 6 רמות כותרת:

</div>

```html
<h1>כותרת ראשית – הגדולה ביותר</h1>
<h2>כותרת משנה</h2>
<h3>תת-כותרת</h3>
<h4>רמה רביעית</h4>
<h5>רמה חמישית</h5>
<h6>רמה שישית – הקטנה ביותר</h6>
```

<div dir="rtl" align="right">

### כללי זהב לכותרות

| כלל | הסבר |
|-----|-------|
| **`<h1>` אחד לדף** | זהו "שם הדף". מנועי חיפוש נותנים לו משקל רב. |
| **אל תדלגו רמות** | אחרי `<h1>` יבוא `<h2>`, לא `<h4>`. |
| **כותרת ≠ טקסט גדול** | אם רק רוצים טקסט גדול – עושים זאת ב-CSS, לא ב-`<h1>`. |
| **היררכיה = תוכן עניינים** | קורא מסך מנווט לפי הכותרות. |

**דוגמה להיררכיה נכונה:**

</div>

```
h1  מתכוני איטליה
├── h2  פסטות
│   ├── h3  ספגטי בולונז
│   └── h3  פנה ארביאטה
└── h2  פיצות
    ├── h3  מרגריטה
    └── h3  פונגי
```

## 2. פסקאות וטקסט

</div>

```html
<p>זוהי פסקה. הדפדפן מוסיף אוטומטית מרווח מעליה ומתחתיה.</p>

<p>
  גם אם אכתוב
  את הטקסט על
  כמה שורות – הדפדפן יציג הכול ברצף.
</p>
```

<div dir="rtl" align="right">

> ⚠️ **כלל חשוב:** הדפדפן **מכווץ רווחים לבנים**. עשרה רווחים = רווח אחד. עשר ירידות שורה = רווח אחד.

---

## 3. עיצוב טקסט – סמנטי מול ויזואלי

זו אחת הנקודות החשובות במודול. יש זוגות תגיות שנראות **זהות** אבל **משמעותן שונה**:

| תגית סמנטית | תגית ויזואלית | תצוגה | מה עדיף? |
|--------------|----------------|--------|-----------|
| `<strong>` – "חשוב" | `<b>` – "מודגש" | **מודגש** | `<strong>` |
| `<em>` – "הדגשה/טעם" | `<i>` – "נטוי" | *נטוי* | `<em>` |

**למה זה משנה?**
קורא מסך יגיד את התוכן של `<strong>` בטון מודגש, ויתעלם מ-`<b>`. מנוע חיפוש ייתן משקל רב יותר ל-`<strong>`.

**הכלל הפשוט:** אם הטקסט **חשוב** – `<strong>`/`<em>`. אם זה **רק עניין של מראה** – עשו זאת ב-CSS.

### שאר תגיות הטקסט

</div>

```html
<strong>טקסט חשוב</strong>
<em>טקסט מודגש בטון</em>
<mark>טקסט מסומן בהדגשה צהובה</mark>
<small>טקסט קטן – הערות שוליים, זכויות יוצרים</small>
<del>טקסט מחוק</del>
<ins>טקסט שנוסף</ins>
<sub>כתב תחתי</sub>   <!-- H<sub>2</sub>O -->
<sup>כתב עילי</sup>   <!-- מ<sup>2</sup> -->
<code>קוד בשורה</code>
<kbd>Ctrl + S</kbd>
<abbr title="HyperText Markup Language">HTML</abbr>
<q>ציטוט קצר בתוך שורה</q>
<cite>שם יצירה</cite>
<time datetime="2026-03-15">15 במרץ 2026</time>
```

## 5. ישויות (Entities) – תווים מיוחדים

יש תווים שלא ניתן לכתוב ישירות כי הדפדפן יפרש אותם כקוד. משתמשים ב"ישויות":

| רוצים להציג | כותבים | הערה |
|--------------|---------|-------|
| `<` | `&lt;` | Less Than |
| `>` | `&gt;` | Greater Than |
| `&` | `&amp;` | Ampersand |
| `"` | `&quot;` | מרכאות |
| רווח שלא נשבר | `&nbsp;` | Non-Breaking Space |
| `©` | `&copy;` | זכויות יוצרים |
| `®` | `&reg;` | סימן רשום |
| `™` | `&trade;` | סימן מסחרי |
| `€` | `&euro;` | אירו |
| `₪` | `&#8362;` | שקל |
| `←` | `&larr;` | חץ שמאלה |
| `→` | `&rarr;` | חץ ימינה |
| `•` | `&bull;` | נקודה |
| `…` | `&hellip;` | שלוש נקודות |

**דוגמה:**

</div>

```html
<p>כדי לכתוב פסקה משתמשים בתגית <code>&lt;p&gt;</code>.</p>
<p>&copy; 2026 כל הזכויות שמורות | מחיר: 99&#8362;</p>
```

<div dir="rtl" align="right">

> 💡 `&nbsp;` שימושי כשלא רוצים שהדפדפן ישבור שורה באמצע ביטוי, למשל `דף&nbsp;5`.

## 6. טקסט מעוצב מראש – `<pre>`

התגית `<pre>` היא היוצא מן הכלל: היא **שומרת** רווחים וירידות שורה בדיוק כפי שנכתבו.

</div>

```html
<pre>
   *
  ***
 *****
*******
</pre>
```

<div dir="rtl" align="right">

**שילוב נפוץ – הצגת קוד:**

</div>

```html
<pre><code>function hello() {
  console.log("שלום");
}</code></pre>
```

<div dir="rtl" align="right">

## 7. `<div>` ו-`<span>` – מיכלים כלליים

שתי תגיות "חסרות משמעות" שמשמשות כמיכלים לעיצוב:

| תגית | סוג | תופסת שורה שלמה? |
|-------|-----|-------------------|
| `<div>` | Block | ✅ כן |
| `<span>` | Inline | ❌ לא, רק כרוחב התוכן |

</div>

```html
<div class="card">
  <h3>כותרת הכרטיס</h3>
  <p>טקסט עם <span class="highlight">מילה מודגשת</span> באמצע.</p>
</div>
```

<div dir="rtl" align="right">

> ⚠️ אל תשתמשו ב-`<div>` לכל דבר! במודול 6 נלמד תגיות סמנטיות (`<header>`, `<article>`) שעדיפות עליו.

---

## 8. Block מול Inline – מושג יסוד

| | **Block** | **Inline** |
|---|-----------|-------------|
| רוחב | תופס את כל השורה | רק כרוחב התוכן |
| שורה חדשה | מתחיל בשורה חדשה | ממשיך באותה שורה |
| דוגמאות | `<p>` `<div>` `<h1>` `<hr>` | `<span>` `<a>` `<strong>` `<em>` `<code>` |
| מכיל Block? | ✅ כן | ❌ לא |

</div>

```
┌──────────────────────────────────┐
│ Block (p)                        │  ← תופס את כל הרוחב
└──────────────────────────────────┘
┌──────────────────────────────────┐
│ Block (div)                      │
└──────────────────────────────────┘

טקסט [inline] טקסט [inline] טקסט     ← זורמים באותה שורה
```

## 📋 סיכום התגיות

| תגית | תפקיד | סוג |
|-------|--------|-----|
| `<h1>`–`<h6>` | כותרות | Block |
| `<p>` | פסקה | Block |
| `<div>` | מיכל כללי | Block |
| `<pre>` | טקסט מעוצב מראש | Block |
| `<blockquote>` | ציטוט ארוך | Block |
| `<hr>` | קו מפריד | Block |
| `<span>` | מיכל כללי | Inline |
| `<strong>` `<em>` | הדגשה סמנטית | Inline |
| `<mark>` `<small>` `<del>` `<ins>` | עיצוב טקסט | Inline |
| `<sub>` `<sup>` | כתב תחתי/עילי | Inline |
| `<code>` `<kbd>` | קוד ומקלדת | Inline |
| `<abbr>` `<q>` `<cite>` `<time>` | סמנטיקה של טקסט | Inline |
| `<br>` | ירידת שורה | Inline |
