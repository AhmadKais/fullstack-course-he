לצידם, לאורך כל הקורס, הכיתה בונה יחד אתר אחד:
**[☕ קפה עתיד](../00-class-project/)** – 30 שלבים, שלב בכל שיעור.

| | |
|---|---|
| **הפרויקט המתמשך** | נבנה **בכיתה**, יחד, בקצב השיעורים |
| **הפרויקטים כאן** | נבנים **לבד**, אחרי שהחומר נלמד |

התלמיד שמסיים את שניהם יוצא עם אתר שנבנה שלב-שלב **ועם** עבודות

## 🎓 המלצות להערכה

- **לתת בריף, לא מדריך.** הפרויקט הוא המקום שבו התלמיד מתמודד עם החלטות בעצמו.
- **לדרוש git.** לפחות commit אחד לכל אבן דרך.
- **קוד ריוויו הדדי** בין תלמידים לפני ההגשה – שווה יותר מהערה של המרצה.
- **להעריך תהליך, לא רק תוצאה.** דף שנראה פשוט אך כתוב נקי עדיף על דף מרשים עם `!important` בכל שורה.
