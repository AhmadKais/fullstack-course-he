1. מצבי אינטראקציה

רחפו עליי · ולחצו עליי · קישור שאולי ביקרתם בו

נסו גם ללחוץ Tab — תראו את סימון המיקוד.

a:hover / a:active / a:focus-visible / a:visited

⚠️ הסדר חשוב: :link → :visited → :hover → :active. ראשי תיבות לזכירה: LoVe HAte. סדר אחר יגרום לחלק מהכללים פשוט לא לעבוד.

4. מצבי טופס

שימו לב: השדות נשארים אפורים כל עוד הם ריקים (בזכות :placeholder-shown), ומשנים צבע רק אחרי הקלדה. זו תבנית עיצוב מקובלת — לא להאשים את המשתמש לפני שהתחיל.

input:valid / input:invalid / input:placeholder-shown

5. פסאודו-אלמנטים

הקוד הטוב ביותר הוא קוד שלא נכתב

.quote::before { content: "« "; }

אות פתיחה מוגדלת היא טכניקה טיפוגרפית עתיקה מעולם הדפוס. ב-CSS משיגים אותה בשתי שורות בלבד, בעזרת ::first-letter. השורה הראשונה כולה מודגשת בזכות ::first-line.

לפסקה הזו יש נקודה ירוקה שנוצרה ב-CSS בלבד

.badge::before { content: ""; width: 12px; ... }

⚠️ שימו לב: גם כשהתוכן ריק, חובה לכתוב content: "";. בלעדיו הפסאודו-אלמנט לא ייווצר כלל.

סמנו את הטקסט הזה עם העכבר וראו את צבע הסימון המותאם.

::selection { background: #fbd38d; }
