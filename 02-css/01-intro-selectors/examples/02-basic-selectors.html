סלקטורים בסיסיים

הפסקה הזו משתמשת ב-p.intro — צירוף של תגית ומחלקה.

1. סלקטור תגית

הפסקה הזו אפורה, כי הכלל p חל על כל הפסקאות בדף.

p { color: #4a5568; }

2. סלקטור מחלקה

בפסקה הזו יש מילים מודגשות ועוד מילים מודגשות — מחלקה יכולה לחזור כמה פעמים שרוצים.

.highlight { background: #fff3bf; }

3. סלקטור מזהה

לפסקה הזו יש מזהה ייחודי. מזהה יכול להופיע פעם אחת בלבד בכל הדף.

#special { border: 2px solid #2b6cb0; }

4. שתי מחלקות באותו אלמנט

כרטיס רגיל — יש לו רק class="card"
כרטיס מודגש — יש לו class="card featured", ולכן חלים עליו שני הכללים.
.card.featured { } /* בלי רווח = אותו אלמנט */

5. ⚠️ ההבדל הקריטי: רווח או לא

אני בתוך .box

אני .inner בתוך .box — ולכן אני צבוע.

.box .inner /* עם רווח = inner בתוך box */ .box.inner /* בלי רווח = אלמנט עם שתי המחלקות */

זו אחת הטעויות הנפוצות ביותר. רווח מיותר או חסר משנה לגמרי את משמעות הסלקטור.

🧪 תרגול מהיר

פתחו F12, בחרו כל אלמנט בדף, וראו בלשונית Styles איזה כללים חלים עליו.
