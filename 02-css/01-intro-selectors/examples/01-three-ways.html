שלוש דרכים לשלב CSS

א׳ – קובץ חיצוני ✅

הפסקה הזו מעוצבת מהקובץ css/style.css. זו הדרך הנכונה. 

<link rel="stylesheet" href="css/style.css">
  • קובץ אחד משרת את כל הדפים באתר
  • הדפדפן שומר אותו במטמון – טעינה מהירה יותר
  • הפרדה נקייה: תוכן ב-HTML, עיצוב ב-CSS

ב׳ – CSS פנימי 🟡

הפסקה הזו מעוצבת מתגית <style> שבתוך ה-head. 

<style>
  .internal-demo { background: #e6f7ff; }
</style>

מתאים לדף בודד או לניסוי מהיר. בדוגמאות הקורס נשתמש בזה כדי שכל קובץ יהיה עצמאי.

ג׳ – Inline ❌

הפסקה הזו מעוצבת בתכונת style שלה עצמה. 

<p style="color: red;">טקסט</p>
  • ❌ אין שימוש חוזר – צריך להעתיק לכל אלמנט
  • ❌ ספציפיות 1000 – כמעט בלתי אפשרי לדרוס
  • ❌ מערבב תוכן ועיצוב

🧪 נסו בעצמכם

  1. פתחו את css/style.css ושנו את הצבע של .external-demo.
  2. שמרו – Live Server ירענן והשינוי יופיע.
  3. עכשיו נסו לדרוס את הכלל החיצוני מתוך תגית ה-<style>. מי מנצח?
  4. ולבסוף – נסו לדרוס את שניהם עם style="".
