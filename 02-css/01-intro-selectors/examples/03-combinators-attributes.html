סלקטורים של יחסים ותכונות

1. צאצא (רווח) — בכל עומק

קישור ברמה ראשונה

קישור בעומק שלוש רמות — גם הוא נצבע, כי הסלקטור חל על כל הצאצאים.

.demo-desc a { color: #c53030; }

2. ילד ישיר (>) — רק רמה אחת

  • אני ילד ישיר ✅ (ירוק)
  • גם אני ילד ישיר ✅ (ירוק)
    • אני נכד ❌ (לא נצבע)
    • גם אני נכד ❌
  • ילד ישיר ✅
.demo-child > li { background: #c6f6d5; }

3. אח סמוך (+) — רק הראשון שאחרי

כותרת

אני הפסקה הראשונה מיד אחרי הכותרת ✅ (כחול)

אני הפסקה השנייה ❌ (לא נצבעת — כבר לא "סמוכה")

אני השלישית ❌

.demo-adj h3 + p { background: #bee3f8; }

4. כל האחים שאחרי (~)

אני לפני הכותרת ❌

כותרת

אני אחרי ✅ (קו סגול)

גם אני אחרי ✅

וגם אני ✅

.demo-sib h3 ~ p { border-right: 3px solid #805ad5; }

5. סלקטורים של תכונות

קישור חיצוני — קיבל חץ אוטומטית

מדריך למשתמש — זוהה כקובץ PDF

שלחו מייל — קיבל אייקון מעטפה

03-1234567 — קיבל אייקון טלפון

קישור פנימי רגיל — בלי תוספת

a[target="_blank"]::after { content: " ↗"; }
a[href$=".pdf"]::after    { content: " (PDF)"; }
a[href^="mailto"]::before { content: "✉ "; }
a[href^="tel"]::before    { content: "☎ "; }

שימו לב לסימנים: ^= מתחיל ב-, $= מסתיים ב-, *= מכיל.

שימוש בטפסים

input[type="email"] { border: 2px solid #2b6cb0; }

למה זה שימושי? אפשר לעצב שדות לפי הסוג שלהם בלי להוסיף מחלקה לכל אחד ואחד.

⚠️ אזהרת נגישות

התוכן שנוצר ב-content (החצים והאייקונים שלמעלה) הוא קישוט ויזואלי. קוראי מסך מסוימים מתעלמים ממנו. לעולם אל תשימו שם מידע חיוני שאין לו מקבילה בטקסט האמיתי.
