# 📖 מילון מונחים – עברית ↔ אנגלית

## כללי

| אנגלית | עברית | הסבר קצר |
|--------|-------|-----------|
| Front-End | צד לקוח / חזית | כל מה שרץ בדפדפן של המשתמש |
| Back-End | צד שרת / עורף | הקוד שרץ על השרת |
| Browser | דפדפן | Chrome, Firefox, Edge |
| Server | שרת | מחשב שמספק את קבצי האתר |
| Client | לקוח | הדפדפן שמבקש את הקבצים |
| Rendering | רינדור / הצגה | תהליך הפיכת הקוד לתמונה על המסך |
| DevTools | כלי מפתחים | חלון F12 בדפדפן |
| Console | קונסולה | חלון להדפסת הודעות ושגיאות |
| Debugging | ניפוי שגיאות / דיבאג | תהליך איתור ותיקון באגים |
| Bug | באג / תקלה | שגיאה בקוד |
| Deploy | העלאה לאוויר | פרסום האתר באינטרנט |
| Repository (Repo) | מאגר קוד | תיקיית הפרויקט בגיט |

## HTML

| אנגלית | עברית | הסבר קצר |
|--------|-------|-----------|
| Tag | תגית | `<p>` |
| Element | אלמנט / רכיב | תגית פותחת + תוכן + תגית סוגרת |
| Attribute | תכונה / מאפיין | `href="..."` |
| Nesting | הכלה / קינון | תגית בתוך תגית |
| Semantic | סמנטי / משמעותי | תגית שמתארת את תפקיד התוכן |
| Void element | תגית ריקה | תגית ללא סגירה, כמו `<img>` |
| Entity | ישות | `&nbsp;` `&amp;` |
| Accessibility (a11y) | נגישות | התאמה למשתמשים עם מוגבלויות |
| Form | טופס | אזור לאיסוף קלט מהמשתמש |
| Placeholder | טקסט מציין מקום | הטקסט האפור בתוך שדה ריק |

## CSS

| אנגלית | עברית | הסבר קצר |
|--------|-------|-----------|
| Selector | סלקטור / בורר | מי מקבל את העיצוב |
| Property | מאפיין | `color` |
| Value | ערך | `red` |
| Declaration | הצהרה | `color: red;` |
| Rule | כלל | סלקטור + הצהרות |
| Specificity | ספציפיות | מי "מנצח" כשיש התנגשות |
| Inheritance | ירושה | תכונות שעוברות מהורה לילד |
| Box Model | מודל הקופסה | תוכן, ריפוד, מסגרת, שוליים |
| Padding | ריפוד | מרווח פנימי |
| Margin | שוליים | מרווח חיצוני |
| Border | מסגרת / גבול | הקו סביב הקופסה |
| Flexbox | פריסת פלקס | פריסה חד-ממדית |
| Grid | רשת | פריסה דו-ממדית |
| Responsive | רספונסיבי / מגיב | מתאים את עצמו לגודל המסך |
| Media Query | שאילתת מדיה | כלל שחל רק בגודל מסך מסוים |
| Breakpoint | נקודת שבירה | הגודל שבו הפריסה משתנה |
| Viewport | אזור התצוגה | החלק הנראה של הדף |
| Transition | מעבר | שינוי הדרגתי בין שני מצבים |
| Animation | הנפשה / אנימציה | רצף שינויים לאורך זמן |

## JavaScript

| אנגלית | עברית | הסבר קצר |
|--------|-------|-----------|
| Variable | משתנה | שם ששומר ערך |
| Constant | קבוע | משתנה שלא משנים |
| Data type | טיפוס נתונים | מחרוזת, מספר, בוליאני... |
| String | מחרוזת | טקסט |
| Number | מספר | שלם או עשרוני |
| Boolean | בוליאני | `true` / `false` |
| Array | מערך | רשימה מסודרת של ערכים |
| Object | אובייקט | אוסף זוגות מפתח-ערך |
| Property | תכונה | מפתח בתוך אובייקט |
| Method | מתודה / פעולה | פונקציה בתוך אובייקט |
| Function | פונקציה | קטע קוד לשימוש חוזר |
| Parameter | פרמטר | משתנה בהגדרת הפונקציה |
| Argument | ארגומנט | הערך שמועבר בפועל |
| Return value | ערך מוחזר | מה שהפונקציה מחזירה |
| Scope | תחום הכרה | היכן המשתנה קיים |
| Loop | לולאה | חזרה על פעולה |
| Iteration | איטרציה / סבב | סיבוב אחד של הלולאה |
| Condition | תנאי | `if` |
| Operator | אופרטור / אופרנד | `+` `===` |
| Callback | פונקציית קריאה חוזרת | פונקציה שמועברת כארגומנט |
| Event | אירוע | לחיצה, הקלדה, טעינה |
| Event Listener | מאזין אירועים | הקוד שמחכה לאירוע |
| Bubbling | בעבוע | אירוע שעולה מהילד להורה |
| DOM | מודל אובייקט המסמך | ייצוג הדף כעץ אובייקטים |
| Node | צומת | אלמנט בעץ ה-DOM |
| Asynchronous | אסינכרוני | פעולה שלא חוסמת את המשך הקוד |
| Promise | הבטחה | אובייקט שמייצג תוצאה עתידית |
| API | ממשק תכנות | שירות שמחזיר נתונים |
| JSON | פורמט נתונים | תבנית טקסט להעברת נתונים |
| Parse | פענוח / ניתוח | הפיכת טקסט לאובייקט |
| Exception | חריגה | שגיאה שנזרקת בזמן ריצה |
