## 🧠 עקרונות הוראה

1. **קידוד חי (Live Coding) עדיף על מצגת.** כתבו את הקוד מול הכיתה, כולל שגיאות. תלמידים לומדים המון מלראות אתכם מתקנים באג.
2. **טעו בכוונה.** שכחו לסגור תגית, כתבו `=` במקום `===`. שאלו: "למה זה לא עובד?"
3. **DevTools מהיום הראשון.** פתחו את `F12` בכל מפגש. תלמיד שיודע לקרוא שגיאה בקונסול חוסך לכם 50% מהשאלות.
4. **מהצורך לפתרון.** לפני שמלמדים Flexbox – הראו כמה קשה למרכז אלמנט בלעדיו.
5. **חזרה מפוזרת.** בכל מפגש התחילו ב-2 שאלות מהמודול הקודם.

## ⚠️ נקודות קושי נפוצות – לפי מודול

### HTML

| נושא | הקושי | איך לטפל |
|------|--------|-----------|
| תגיות סוגרות | תלמידים שוכחים לסגור | Emmet + Auto Rename Tag; הראו את התוצאה השבורה |
| נתיבים יחסיים | `../` לא ברור | ציירו את עץ התיקיות על הלוח וצעדו בו יחד |
| `alt` בתמונות | נתפס כמיותר | הדגימו קורא מסך או כבו תמונות בדפדפן |
| ההבדל בין `id` ל-`class` | בלבול | "ת״ז אחת לאדם אחד, חולצה אחידה להרבה אנשים" |

### CSS

| נושא | הקושי | איך לטפל |
|------|--------|-----------|
| ספציפיות | "למה הכלל שלי לא עובד?" | לימדו לחשב ניקוד; הראו ב-DevTools כלל מחוק בקו |
| `box-sizing` | הרוחב "יוצא גדול יותר" | הדגימו עם/בלי `border-box` זה לצד זה |
| קריסת margin | מרווחים לא מתחברים | דוגמה חיה + פתרון עם `padding` או `gap` |
| Flexbox – צירים | בלבול בין `justify` ל-`align` | "justify = לאורך הציר הראשי". שנו `flex-direction` והראו שהכול מתהפך |
| Grid מול Flex | מתי מה | "Flex = שורה אחת או עמודה אחת. Grid = טבלה דו-ממדית" |
| רספונסיביות | שוכחים `meta viewport` | תמיד להראות במצב מכשיר נייד ב-DevTools |

### JavaScript

| נושא | הקושי | איך לטפל |
|------|--------|-----------|
| `=` מול `==` מול `===` | קלאסיקה | טבלה על הלוח + תרגילי "מה יודפס" |
| טיפוסים ו-`+` | `"5" + 5 === "55"` | הריצו בקונסול, בקשו ניחוש לפני |
| Scope | משתנה "נעלם" | ציירו קופסאות מקוננות |
| `return` | חושבים ש-`console.log` מחזיר ערך | הדגימו פונקציה בלי `return` שמחזירה `undefined` |
| `map` מול `forEach` | מתי מה | "`forEach` עושה. `map` מייצר מערך חדש" |
| `this` | מבלבל מאוד | בקורס בסיסי – להסתפק ב-`this` בתוך אובייקט ובאירועים |
| DOM לפני טעינה | `null` מ-`querySelector` | לימדו לשים `<script>` בסוף `body` או `defer` |
| אסינכרוניות | "למה זה מדפיס אחרי?" | דוגמת `setTimeout` עם 0 מילישניות |
| `fetch` | שוכחים `await response.json()` | ציירו 2 שלבים: תשובה → פענוח |

## 📝 שימוש בקבצי הקורס

- **`README.md`** של כל מודול = מערך השיעור שלכם. אפשר להקרין ישירות.
- **`examples/`** = לפתוח ב-Live Server תוך כדי ההסבר. כל דוגמה עצמאית וניתנת להרצה.
- **`exercises/README.md`** = להקרין את הדרישות; התלמידים עובדים בקבצי השלד.
- **`solutions/`** = **לא לפתוח בכיתה לפני שהתלמידים ניסו.** להראות רק בסיכום.
- **`quiz.md`** = אפשר כחידון פתיחה של המפגש הבא (10 דקות) או כשיעורי בית.

## 🔗 קישור לקורס ה-SQL

הקורס הזה מלמד **צד לקוח בלבד**. נקודות חיבור טבעיות לקורס ה-SQL הנפרד:

- **מודול JS 06 (אובייקטים)** – אובייקט = רשומה, מערך אובייקטים = טבלה. שווה להזכיר.
- **מודול JS 12 (Fetch)** – הנתונים שמגיעים מה-API מגיעים בפועל מבסיס נתונים. כאן מתחבר הקורס השני.
- **פרויקט הגמר** – אפשר להנחות תלמידים לתכנן את מבנה הנתונים כאילו הוא טבלאות SQL, גם אם בפועל הוא נשמר ב-`localStorage`.
