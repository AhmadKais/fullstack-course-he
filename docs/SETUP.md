# 🛠️ מדריך התקנה – סביבת עבודה

זמן משוער: 20 דקות. יש לבצע לפני המפגש הראשון.

---

## 1. דפדפן

התקינו **Google Chrome** (או Edge / Firefox).
בקורס נשתמש הרבה בכלי המפתחים (DevTools) – פתיחה בעזרת `F12` או `Ctrl + Shift + I`.

## 2. עורך קוד – VS Code

הורדה: <https://code.visualstudio.com>

לאחר ההתקנה, התקינו את התוספים הבאים (אייקון הריבועים בסרגל הצד → חיפוש → Install):

| תוסף | מה הוא עושה | חובה? |
|------|--------------|-------|
| **Live Server** | מריץ את הדף בדפדפן ומרענן אוטומטית בכל שמירה | ✅ חובה |
| **Prettier** | מיישר ומסדר את הקוד אוטומטית | ✅ חובה |
| **Auto Rename Tag** | שינוי תגית פותחת משנה גם את הסוגרת | מומלץ |
| **Error Lens** | מציג שגיאות ישירות ליד השורה | מומלץ |

> 💡 אם פתחתם את תיקיית הקורס ב-VS Code, יופיע חלון "Install recommended extensions" – לחצו Install.

## 3. הפעלת דף בדפדפן

יש שתי דרכים:

1. **Live Server (מומלץ):** לחיצה ימנית על קובץ `.html` → `Open with Live Server`.
   הדף נפתח בכתובת `http://127.0.0.1:5500` ומתעדכן בכל שמירה.
2. **פתיחה ידנית:** לחיצה כפולה על הקובץ במנהל הקבצים.
   ⚠️ בדרך זו חלק מהתרגילים ב-JavaScript (במיוחד `fetch` ומודולים) **לא יעבדו** בגלל מדיניות אבטחה של הדפדפן.

## 4. הגדרות מומלצות ל-VS Code

`File → Preferences → Settings` (או `Ctrl + ,`), ואז חיפוש:

- `Format On Save` → ✅ מסומן
- `Tab Size` → `2`
- `Word Wrap` → `on`

## 5. הורדת חומרי הקורס

</div>

```bash
# אפשרות א׳ – עם Git
git clone <כתובת-הריפו>
cd Full_Stack
code .
```

**אפשרות ב׳ – ללא Git:** בעמוד הריפו לוחצים על הכפתור הירוק `Code` → `Download ZIP` → מחלצים → פותחים ב-VS Code.

## 6. איפה שומרים עבודות?

צרו לעצמכם תיקייה בשם `students/` בתוך תיקיית הקורס. היא כבר מוגדרת ב-`.gitignore`, כך שהעבודות שלכם לא יתנגשו עם עדכוני החומר.

</div>

```
Full_Stack/
├── 01-html/          ← חומר הקורס (לא לשנות)
├── 02-css/
├── 03-javascript/
└── students/         ← כאן שומרים את התרגילים שלכם
    └── ahmad/
        └── html-ex1.html
```

## 7. קיצורי מקלדת שיחסכו לכם זמן

| קיצור | פעולה |
|-------|--------|
| `!` + `Tab` | יוצר שלד HTML שלם (Emmet) |
| `Ctrl + S` | שמירה |
| `Ctrl + /` | הפיכת שורה להערה |
| `Alt + ↑ / ↓` | הזזת שורה למעלה/למטה |
| `Shift + Alt + ↓` | שכפול שורה |
| `Ctrl + D` | בחירת המופע הבא של אותה מילה |
| `Ctrl + Shift + P` | תפריט הפקודות |
| `F12` (בדפדפן) | פתיחת כלי המפתחים |

## 8. בדיקה שהכול עובד

צרו קובץ `test.html` עם התוכן הבא, הריצו ב-Live Server, וודאו שאתם רואים כותרת אדומה והודעה ב-Console:

</div>

```html
<!DOCTYPE html>
<html lang="he" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>בדיקה</title>
  <style> h1 { color: red; } </style>
</head>
<body>
  <h1>הסביבה עובדת! 🎉</h1>
  <script> console.log("JavaScript עובד"); </script>
</body>
</html>
```

<div dir="rtl" align="right">

אם ראיתם כותרת אדומה בעברית מימין לשמאל, וב-Console (F12) את ההודעה – אתם מוכנים לקורס.
