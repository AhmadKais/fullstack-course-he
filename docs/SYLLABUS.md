## 🎯 יעדי הקורס

בסיום הקורס הסטודנט יוכל:

1. לבנות אתר סטטי מלא ותקני ב-HTML סמנטי.
2. לעצב אתר רספונסיבי באמצעות CSS, Flexbox ו-Grid.
3. לכתוב לוגיקה ב-JavaScript: משתנים, תנאים, לולאות, פונקציות, מערכים ואובייקטים.
4. לתפעל את ה-DOM ולהגיב לאירועי משתמש.
5. למשוך נתונים מ-API חיצוני ולהציגם בדף.
6. לשמור מצב בדפדפן ולבצע דיבאג באמצעות כלי המפתחים.
